# Code Bird Character Guide

## Purpose

This guide defines how to design Codori characters consistently across illustration, stickers, apps, learning material, merchandise, and social media.

The character system should stay simple enough that each bird can be recognized at tiny sizes and reproduced across many production formats.

## Global Character Rules

- Keep silhouettes simple and readable.
- Use one chord family per character.
- Do not split voicings into separate characters.
- Avoid excessive color variations.
- Prefer cute emotional clarity over technical detail.
- Use music motifs as accents, not as the whole design.
- Make every character work without a background.
- Make every character work without text labels when possible.

## Base Body Template

All Code Birds should share a family resemblance.

Recommended base:

- Compact round bird body
- Large head-to-body ratio
- Small triangular beak
- Two simple feet
- Short rounded wings
- Small tail or feather mark
- Large expressive eyes
- Clean outline

The base body can stretch slightly per character, but the cast should look like one world.

## Proportions

Suggested proportions:

- Head and body combined: 70-80% of total height
- Eyes: large enough to read at sticker size
- Wings: visible but not detailed
- Feet: small and iconic
- Accessories: no more than 15-20% of total silhouette

## Line Style

Use clean friendly outlines.

Recommended:

- Rounded strokes
- Minimal internal lines
- Clear separation between body, wing, and accessory
- No dense hatching
- No tiny notation lines inside the body

For merchandise, the line style should survive embroidery, enamel pins, acrylic printing, and small stickers.

## Expression System

Each bird needs a default expression plus reusable sticker expressions.

Core expression set:

- Happy
- Thinking
- Surprised
- Sleepy
- Cheering
- Thank you
- Sorry
- OK
- Confused
- Excited

Expressions should be created by changing eyes, beak, wing pose, body tilt, and small motion marks. Do not change the underlying character identity.

## Pose System

Use poses as flexible states.

Good pose types:

- Perching
- Hopping
- Singing
- Bowing
- Waving
- Floating
- Thinking with wing near beak
- Holding a tiny chord tag
- Sitting on staff lines

Avoid:

- Complex action scenes
- Hard-to-read instrument playing in tiny scale
- Props that hide the silhouette
- Poses that require too much anatomy

## Color Identity Rules

Use color in two layers:

- Base family color: identifies the chord type or bird species.
- Key identity: added using small accents, aura colors, tags, or symbols.

Avoid making the entire bird change color for every key. The bird species should remain recognizable, while the key appears as a controlled secondary layer.

## Character Families

### Major Bird

Role: bright, open, reliable.

Design:

- Upright round posture
- Base family color: warm yellow
- Key identity should be added using small accents, aura colors, tags, or symbols
- Clear open eyes
- Small coral cheek or wing accent
- Simple note charm or crest

Sticker personality:

- Cheerful
- Encouraging
- Direct
- Friendly leader

### Minor Bird

Role: gentle, thoughtful, tender.

Design:

- Slightly lowered or tucked posture
- Base family color: soft blue
- Key identity should be added using small accents, aura colors, tags, or symbols
- Lavender accent
- Soft eyelids or reflective eyes
- Rounded wing held close

Sticker personality:

- Quiet support
- Sympathy
- Thinking
- Soft sadness without becoming gloomy

### Seventh Bird

Role: playful, active, expressive.

Design:

- Slight body tilt
- Base family color: mint green
- Key identity should be added using small accents, aura colors, tags, or symbols
- Orange accent
- One lively raised wing
- Small sparkle or bounce mark

Sticker personality:

- Mischievous but friendly
- Energetic
- Good for reactions
- A little jazzy without visual clutter

### Major Seventh Bird

Role: dreamy, smooth, refined.

Design:

- Base family color: pale aqua
- Key identity should be added using small accents, aura colors, tags, or symbols
- Gold accent
- Calm half-smile
- Floating note or tiny halo-like music mark
- Smooth elegant feather shape

Sticker personality:

- Relaxed
- Dreaming
- Elegant approval
- Gentle celebration

### Minor Seventh Bird

Role: mellow, cozy, warm.

Design:

- Base family color: dusty teal
- Key identity should be added using small accents, aura colors, tags, or symbols
- Cream accent
- Rounded cozy shape
- Soft smile
- Wing wrapped slightly inward like a hug

Sticker personality:

- Chill
- Comforting
- Casual agreement
- Warm thanks

### Diminished Bird

Role: tense, tiny, unstable, cute-nervous.

Design:

- Smaller compact body
- Base family color: cool gray
- Key identity should be added using small accents, aura colors, tags, or symbols
- Violet accent
- Slight angular crest
- Wide worried eyes

Sticker personality:

- Nervous
- Oops
- Suspense
- Tiny panic

Important: keep this character cute, not scary.

### Augmented Bird

Role: expanded, surprised, unusual.

Design:

- Puffed or slightly stretched body
- Base family color: peach
- Key identity should be added using small accents, aura colors, tags, or symbols
- Red-orange accent
- Raised crest
- Round surprised eyes

Sticker personality:

- Surprise
- Discovery
- Strange but fun
- Big reaction

### Suspended Bird

Role: waiting, hovering, unresolved.

Design:

- Base family color: sky blue
- Key identity should be added using small accents, aura colors, tags, or symbols
- White accent
- One lifted foot or floating pose
- Eyes looking upward or sideways
- Simple held-breath expression

Sticker personality:

- Waiting
- Almost there
- Questioning
- Suspense with sweetness

### Sixth Bird

Role: friendly, nostalgic, settled.

Design:

- Base family color: soft pink
- Key identity should be added using small accents, aura colors, tags, or symbols
- Warm brown accent
- Gentle smile
- Ribbon-like wing or tail curve
- Stable sitting pose

Sticker personality:

- Kind
- Homey
- Thankful

### Ninth / Extension Bird

Role: airy, colorful, extended.

Design:

- Base family color: light lilac
- Key identity should be added using small accents, aura colors, tags, or symbols
- Cyan accent
- Slightly taller feather or floating note
- Open curious eyes
- Subtle star-note motif

Sticker personality:

- Wonder
- Inspiration
- New idea
- Light magical feeling

## Labeling Rules

Labels should be optional.

Allowed label formats:

- Small chord-family label under the character
- Small chord-symbol tag held by the bird
- App UI text outside the illustration
- Learning card title

Avoid placing dense theory labels on the character body.

## Background Rules

Characters should be designed transparent-first.

Backgrounds may be added for:

- Social posts
- Lesson cards
- Merchandise packaging
- Seasonal campaigns

Backgrounds should not be required for recognition.

## Merchandise Rules

For physical goods:

- Avoid tiny marks below 2 mm.
- Use strong outer silhouette.
- Keep accessories attached or close to the body.
- Prefer large facial features.
- Test each design in one-color silhouette.

## App Rules

For app usage:

- Prepare icon-scale head crops.
- Prepare idle, correct, incorrect, loading, and celebration states.
- Keep motion loops simple.
- Use character color consistently with UI tokens.

## LINE Sticker Rules

For LINE sticker usage:

- Prioritize expression over theory.
- Use short phrases.
- Keep character large in frame.
- Avoid thin staff lines unless clearly visible.
- Make text optional for international reuse.

## Open Questions

- Final proper names for each bird are not yet approved.
- Whether the first art batch should include all ten starter families or a smaller pilot cast remains unresolved.
- Final line thickness should be decided after testing at LINE sticker export size.
- Whether Japanese handwritten text, English text, or no text should be the default sticker direction remains unresolved.
