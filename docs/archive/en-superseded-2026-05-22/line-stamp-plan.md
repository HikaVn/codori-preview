# LINE Stamp Plan

## Purpose

This document plans the first Codori LINE sticker set. The set should sell the characters as cute reaction IP first and quietly support chord learning second.

## Product Direction

The first sticker pack should be usable by people who do not know music theory.

Music fans should notice the chord personalities, but everyday users should still understand each sticker immediately.

## Recommended First Pack Size

Start with 16 stickers for production control.

This size is large enough to show the concept while keeping the first illustration batch consistent.

Possible later expansions:

- 24-sticker full set
- 40-sticker complete reaction set
- Seasonal set
- Music lesson set
- Animated sticker set

## Starter Character Selection

Recommended first pack cast:

- Major
- Minor
- Seventh
- Major Seventh
- Diminished
- Augmented
- Suspended
- Ninth / Extension

Reason:

This gives a strong emotional range while avoiding too many visually similar mellow-family birds in the first batch.

Minor Seventh and m7-5 can be added in pack two or included if the first pack expands beyond 16.

## Text Strategy

Recommended first direction:

- Keep phrases short.
- Use Japanese as the primary sticker text for production planning.
- Prepare English alternatives only when needed for international variants.
- Ensure the illustration still works if text is removed.

## Composition Rules

- Character should occupy most of the sticker area.
- Expression must read at small phone size.
- Keep backgrounds transparent or extremely simple.
- Avoid dense music notation.
- Use one or two motion marks only when needed.
- Text should not cover the character silhouette.
- Chord symbols can appear as tiny optional tags, not as the main message.

## Production Specs To Confirm

Before final export, confirm current LINE Creators Market requirements.

Expected production planning assumptions:

- Transparent PNG
- Main sticker artwork prepared at high resolution
- Safe margins around character and text
- Separate main image and tab image assets
- Consistent naming convention

Because platform requirements can change, final dimensions should be verified immediately before export.

- `codori_line_04_yay_maj7.png`

Recommended working folders:

- `assets/line/source`
- `assets/line/export`
- `assets/line/review`

## Review Checklist

Before submission:

- Character identity is clear.
- Emotion is readable without text.
- Text is readable at phone size.
- Silhouette is simple.
- No excessive colors were introduced.
- Music motif is secondary.
- Transparent edges are clean.
- Pack feels cohesive as a set.
