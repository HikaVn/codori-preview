# 旧英語版ドキュメント退避メモ

このフォルダには、2026-05-22時点で`docs/en/`に残っていた旧英語版ドキュメントを退避しています。

現在のCodoriプロジェクトでは、`docs/ja/`を日本語正本として扱います。

旧英語版は以下の理由で通常参照対象から外します。

- 現在の仕様と異なる記述が残っている
- 「キー = 全身色」のように、現行方針より古いルールが含まれる
- LINEスタンプや画像生成方針が、現在のアプリ主軸の進行とずれている

今後、英語版が必要になった場合は、この退避版を翻訳元として使うのではなく、`docs/ja/`の最新正本から新しく英語版を作成します。
