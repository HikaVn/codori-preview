# Image Generation Prompts

## Purpose

This document provides production-ready image prompt templates for Codori concept art, character sheets, LINE sticker drafts, and social media assets.

Prompts should preserve the core system:

- Cute bird character IP first
- One chord family per character
- No voicing-specific characters
- Simple readable silhouettes
- Controlled color variation
- Minimal music motifs

## Global Style Prompt

Use this style block as the foundation for character generation:

```text
cute original mascot character, small round bird, simple readable silhouette, clean rounded outline, big expressive eyes, tiny beak, tiny feet, short rounded wings, soft friendly shape language, minimal music-note accent, character design sheet quality, sticker-ready, transparent background, simple flat colors with gentle shading, high readability at small size, charming Japanese mascot style, no complex costume, no realistic feathers, no dense music notation, no extra characters
```

## Global Negative Prompt

Use this to prevent drift:

```text
realistic bird, detailed feathers, complex costume, many accessories, busy background, sheet music covering the body, human body, hands, fingers, scary monster, aggressive expression, excessive color palette, multiple different birds, text errors, illegible chord symbols, photorealistic, Pixar-style CG, glossy mascot render, realistic 3D mascot, watercolor bleed, overly thin lines, tiny details, instrument with many strings, separate voicing variants
```

Keep the same body shape, colors, accessory, and silhouette across all expressions. Transparent or plain white background. Clean production character sheet layout. No text labels. No extra character variants. No separate voicing designs.

## Production Notes

- Generate transparent-background character art first.
- Test each design at small sticker size before expanding expressions.
- Keep seed and prompt records for each approved character.
- Do not approve a character if it only differs by color and not silhouette or expression.
- Do not create root-note variants as separate characters.
- Do not create voicing variants as separate characters.

## Open Questions

- Final image model and prompt syntax may require adjustment.
- Final export dimensions for LINE stickers should be verified before production.
- Whether prompts should target soft mascot raster art or hand-drawn raster art needs an art test.
- Final bilingual text strategy for sticker prompts remains undecided.
