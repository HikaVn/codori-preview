# Code Bird Chord System

## Purpose

This document defines the working chord-character system for Codori. The goal is to keep character design consistent, scalable, and educational without letting music theory complexity fracture the IP.

## System Priority

Codori prioritizes cute character IP design over strict music theory completeness.

The system should:

- Help people remember chord qualities
- Support beginner-friendly learning
- Keep characters stable across products
- Avoid excessive variants
- Avoid turning every technical distinction into a separate character

## Core Rule

One chord family equals one character.

Do not create separate characters for:

- Different voicings
- Inversions
- Octave placements
- Guitar shapes
- Piano fingerings
- Open versus closed voicing
- Register differences
- Key transpositions

These can be shown as poses, props, lessons, cards, or app states, but not as new core characters.

## Character Unit

A Code Bird represents a chord quality or chord family, not a root note.

For example:

- C major, F major, and G major all use the same Major bird family.
- C minor and A minor use the same Minor bird family.
- Cmaj7 and Fmaj7 use the same Major Seventh bird family.

Root note can be shown separately with:

- A small label
- A perch tag
- A lesson card
- A background key color
- App UI text

Root note should not redefine the character.

## Recommended Starter Families

| Family | Symbols | Feeling | Character Direction |
| --- | --- | --- | --- |
| Major | C, Cmaj | Bright, open, confident | Round upright bird with clear eyes |
| Minor | Cm, Cmin | Soft, thoughtful, tender | Slightly lowered posture and gentle eyes |
| Seventh | C7 | Playful, bluesy, active | Tilted pose, lively wing, small sparkle |
| Major Seventh | Cmaj7, CM7 | Dreamy, refined, floating | Calm elegant bird with smooth accent |
| Minor Seventh | Cm7, Cmin7 | Mellow, warm, relaxed | Cozy bird with softer wing curve |
| Diminished | Cdim, Cdim7 | Nervous, tiny, unstable | Small compact bird with angular crest |
| Augmented | Caug, C+ | Surprised, expanding, strange | Puffed shape or lifted crest |
| Suspended | Csus2, Csus4 | Waiting, hovering, unresolved | Bird with lifted foot or floating pose |
| add9 | Cadd9 | Sparkling, youthful, airy | Small bird with star-note motif and open curious eyes |
| m7-5 | Cm7-5 | Unstable, urban, emotional tension | Slightly nervous owl-like bird with inward posture |
| Ninth / Extension | C9, Cmaj9, Cm9 | Airy, colorful, extended | Slightly taller feather or floating-note motif |

## Expansion Rules

New characters may be added when a chord family has:

- A distinct beginner-level identity
- A clear emotional role
- A simple visual silhouette
- Repeated educational value
- Use across multiple products

New characters should not be added merely because a symbol exists.

## Extension Handling

Extensions should be handled carefully.

Recommended default:

- Ninth / Extension bird can cover common extended color chords at first.
- add9 has its own character because it has a strong beginner-friendly ukulele identity.
- Specific extension families can become separate characters only if the product needs them and the designs stay readable.

Examples that should remain lesson states unless justified:

- 11th
- 13th
- altered dominant
- secondary dominants
- slash chords

## Voicing Handling

Voicings are variations of the same character, not separate characters.

Allowed voicing representation:

- Different pose
- Different prop
- Lesson overlay
- Keyboard or fretboard diagram beside the bird
- App animation state
- Social carousel explanation

Not allowed:

- New bird character only for first inversion
- New bird character only for drop 2 voicing
- New bird character only for guitar open chord shape
- New bird character only for piano shell voicing

## Key Handling

Keys and root notes are labels or contexts.

Allowed:

- A `C` tag near the Major bird
- A keyboard highlight behind the character
- A key-colored background in learning material
- A small sign reading `Fmaj7`

Not allowed:

- Twelve different Major birds for the twelve roots
- Color variants for every key
- Separate silhouettes for each root

## Color System

Use color to support family recognition, not to encode every theoretical attribute.

Recommended initial mapping:

| Family | Main Color | Accent |
| --- | --- | --- |
| Major | Warm yellow | Soft coral |
| Minor | Soft blue | Lavender |
| Seventh | Mint green | Orange |
| Major Seventh | Pale aqua | Gold |
| Minor Seventh | Dusty teal | Cream |
| Diminished | Cool gray | Violet |
| Augmented | Peach | Red-orange |
| Suspended | Sky blue | White |
| add9 | Light yellow-green | Star gold |

This is a draft palette. Avoid adding more color variants until the starter cast is visually tested.

## Accessory System

Accessories should be minimal and meaning-driven.

Allowed accessory types:

- Tiny scarf
- Small tag
- One crest feather
- Small music-note charm
- One simple hat-like accent
- A simple floating note

Avoid:

- Complex costumes
- Multiple accessories per character
- Real instrument details on every bird
- Tiny theory symbols that disappear at sticker size

## Educational Layers

The same character can appear at different learning depths.

### Beginner Layer

- Chord name
- Mood
- Very simple example
- Cute expression

### Learning Layer

- Chord symbol
- Basic interval formula
- Example root note
- Sound description

### App / Advanced Layer

- Keyboard or fretboard visualization
- Inversion selector
- Voicing examples
- Playback
- Quiz states

The character remains unchanged across layers.

## Design Change Policy

Do not redesign the core system without documenting why.

Any future system change should record:

- What changed
- Why the change was necessary
- What products it affects
- Whether existing characters remain valid
- How old assets should be migrated

## Open Questions

- Whether `Ninth / Extension` should be one starter character or split later into separate `Ninth`, `Eleventh`, and `Thirteenth` families.
- Whether diminished triad and diminished seventh should share one character permanently.
- Whether suspended second and suspended fourth should share one character permanently.
- Whether sixth and minor sixth should be one family or two if educational products require nuance.
- Whether Sixth should remain an optional future expansion family or become part of a later starter set.
- Final color palette must be tested in actual sticker-size artwork.
