# Codori m7 / 夜雀 正式候補 画像生成プロンプト

## このファイルについて

このファイルは、`m7 / 夜雀` の正式キャラクター候補を画像生成するための最終指示文です。

目的：

- `m7` を、minorより少しほどけた「夜の余韻」として見分けられる正式鳥にする。
- 初期4鳥 `Major / minor / 7 / add9` と並べても、コード種類の違いが分かるようにする。
- アプリ、LINEスタンプ、SNS、グッズへ展開できるシンプルな鳥IPにする。

注意：

- まだ画像生成はしない。
- まずはこの指示文をChatGPTまたは画像生成ツールへ渡す。
- 生成数は6〜8案まで。
- 採用判断はユーザー確認後に行う。

# 生成時のバリエーション指定

6〜8案を出す場合、以下の範囲で差を出す。

| 案 | 変えてよい要素 | 変えない要素 |
|---|---|---|
| 1 | 眠そうな正面寄り | 丸い体、黒い小くちばし、黒い足 |
| 2 | 少し横を向く | 夜雀らしい小ささ、白い体基準 |
| 3 | 羽を胸元に寄せる | m7の静かな余韻 |
| 4 | 少し目を細める | 悲しすぎない表情 |
| 5 | 小さなDeep Blueアクセント | アクセントを増やしすぎない |
| 6 | 体を少し低くする | 7鳥のような前傾にしない |
| 7 | ふわっと休む姿勢 | add9の星感に寄せない |
| 8 | 口元を少しやわらかくする | minor鳥の単なる色違いにしない |

# 生成後に最初にすること

1. 生成画像に番号を振る。
2. まず見た目だけで、候補A/B/Cを3つ選ぶ。
3. 既存4鳥と横並びで見る。
4. 小サイズでも目、くちばし、足、シルエットが読めるか確認する。
5. その後、正式採用ではなく「修正候補」を1つ選ぶ。

この段階では、まだ正式採用しない。
