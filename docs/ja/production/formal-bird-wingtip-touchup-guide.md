# 基準

羽先端の基準は、元々のCの羽。

基準形：

```text
小さな丸い2山の割れ
```

意味：

- 先端が尖らない
- 羽毛のように細かく割れない
- 手指のように見えない
- 2つの小さな丸い山に見える
- 小サイズでは、丸い小さな凹みとして読めればよい

---

# 共通ルール

- 見えている羽先だけ、C基準の小さな丸い2山の割れに揃える。
- 体や角度で隠れて見えない羽先は、無理に割れを見せない。
- 割れは輪郭線そのものの小さな凹みとして作る。内側に線を足して表現しない。
- ラスター局所編集で輪郭品質を保てない場合は、割れ追加をしない。
- 現行正式4鳥には、ラスタ局所修正で割れを追加しない。
- コード種類の差は、羽先の形ではなく、体型・表情・ポーズ・アクセントで出す。
- 羽先端の割れは、キャラクター差ではなくCodori共通記号として扱う。
- 7の上げ羽やadd9の流れ羽でも、先端形状はC基準から外さない。

# 個別タッチアップ方針

## C / Major

状態：

- 基準。
- 元々のCの両羽先にある小さな丸い割れを正とする。

タッチアップ：

- 原則変更しない。
- 線の荒れや欠けがある場合のみ整える。

---

## Cm / minor

状態：

- 羽を胸元に抱えているため、羽先端の割れは見えにくい。

タッチアップ：

- 見えている外側または下側の羽先だけ、C基準の小さな丸い2山にする。
- 抱え込んで隠れる部分は、無理に割れを追加しない。
- 内側の抱え線に割れ線を足さない。
- かわいさより先に「手の指」に見えないことを確認する。

NG：

- 抱え羽を指のように分割する。
- 割れを強く描きすぎて不安そうな手に見せる。

---

## C7 / Seventh

状態：

- 上げ羽の先端が見えやすい。
- 羽先端が割れていないと、C基準から外れて見えやすい。

タッチアップ：

- 上げ羽の先端に、Cと同じ小さな丸い2山の割れを入れる。
- 割れ位置は羽の外端に流しすぎず、Cのお手本に近い中央寄りの小さな凹みにする。
- 動きは羽の角度とポーズで出す。
- 羽先だけを大きく尖らせない。

NG：

- 羽先をギザギザにする。
- 羽先を鋭くする。
- 手を振っている人間の手のように見せる。

---

## Cadd9 / add9

状態：

- 見上げる姿勢と星アクセントでadd9らしさを出す。
- 羽先端は角度によって見え方が変わる。

タッチアップ：

- 見えている羽先だけ、C基準の小さな丸い2山にする。
- 体の後ろや角度で見えない羽先は、無理に割れを足さない。
- 左右どちらか一方だけ割れて見える状態は避ける。
- 7との差は羽先ではなく、上向き姿勢と星で出す。

NG：

- 羽先を流線型にしすぎてC基準から外す。
- 星アクセントより羽先が目立つ。
- 羽先を尖らせる。

# 数値基準

羽先端のタッチアップ後も、以下を維持する。

```text
鳥面積：C基準 ±10%以内
目サイズ：C基準 ±10%以内
Cadd9：鳥全体はC比で約 -5%
```

```sh

swift tools/check_character_eye_size.swift
```
