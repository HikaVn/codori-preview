# Codori 画像生成ログテンプレート

## このファイルについて

このファイルは、
Codoriの画像生成時に：

- 良かった方向

- 正式採用理由

を記録するためのテンプレート。

目的：

- 同じ失敗を繰り返さない
- “偶然かわいい”を失わない
- /goal前に正式方向を整理する
- AI変更時も世界観維持する
