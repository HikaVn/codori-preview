# Codori Major候補 A/B/C 比較シート

## このファイルについて

このファイルは、CodoriのMajor正式採用案を決める前に、候補A/B/Cを比較するための評価シートです。

目的：

- Major候補を感覚だけで選ばない
- Codoriらしさを言語化する
- minor / 7 / add9へ展開できるか確認する
- 4個パイロットスタンプへ進む前に、人間が判断すべき項目を整理する

重要：

- このファイルは承認前の比較履歴として残す。
- 2026-05-21時点で、Majorは `assets/approved/characters/major.png` を準正式採用とする。
- 次はアプリMVP設計へ進む。

---

# 前提

Major鳥はCodori全体の基準です。

Majorで決まるもの：

- 絵柄の基準
- 顔の基準
- 線の基準
- かわいさの基準
- 世界観の入口
- minor / 7 / add9へ展開するときの親デザイン

Major候補は、単体でかわいいだけでは不十分です。

以下も満たす必要があります。

- 小サイズで読める
- LINEスタンプにできる
- 白黒シルエットで成立する
- 他の鳥へ展開しても崩れない
- Codoriの「やさしい、小さい、音の感情を持つ小鳥」感がある

# A/B/Cを選ぶ基準

## 必須条件

候補A/B/Cに残すには、以下を満たす。

- 第一印象で「この子かわいい」と思える
- Majorらしい安心感がある
- 丸く安定したシルエットがある
- 顔が小サイズで読める
- リアル鳥・Pixar風・企業マスコット風ではない
- 色や装飾を減らしても成立する
- minor / 7 / add9へ展開する余地がある

## A案に向く候補

A案は「最有力候補」です。

選ぶ基準：

- かわいさとCodoriらしさが一番強い
- Majorとして安心感がある
- 迷ったときに基準に戻れる感じがある
- 4鳥へ展開しても世界観が崩れにくい

注意：

- 完成度が高すぎて他の鳥が追いつけない場合は危険。
- 装飾が多くて再現しにくい場合はA案にしない。

## B案に向く候補

B案は「別方向の有力候補」です。

選ぶ基準：

- A案とは違う魅力がある
- 表情、線、丸さ、絵本感などに別の良さがある
- 修正すればA案を超える可能性がある

注意：

- A案の弱点を補う比較対象として残す。
- A案とほぼ同じならB案に残す意味が弱い。

## C案に向く候補

C案は「保険・検証用候補」です。

選ぶ基準：

- A/Bとは違うシルエットや空気感がある
- 展開実験に使える
- 一部だけ採用したい要素がある

注意：

- 単に3番目にかわいい案ではなく、比較価値がある案を残す。
- 採用危険でも、学びが大きい場合はC案にしてよい。
