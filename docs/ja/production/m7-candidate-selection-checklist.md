# 既存4鳥との比較

必ず以下の順で横並び確認する。

```text
Major / minor / 7 / add9 / m7候補
minor / m7候補
7 / m7候補
add9 / m7候補
```

## minorとの違い

m7候補は、minorより：

- 少し力が抜けている
- 悲しさが軽い
- 夜の余韻がある
- しっとりしているが沈みすぎない

NG：

- minor鳥の色違いに見える
- minor鳥より悲しい
- 内向きすぎて重い

## 7との違い

m7候補は、7鳥より：

- 前へ進まない
- いたずらっぽくない
- 動きが少ない
- 夜の余韻が強い

NG：

- 前傾姿勢
- 片羽を大きく上げる
- 目がいたずらっぽい

## add9との違い

m7候補は、add9より：

- 星感が少ない
- 上向きすぎない
- 青春感より夜の余韻
- きらきらより、しっとり

NG：

- 星や月アクセントが多い
- 目が開きすぎて好奇心が強い
- 空気感がadd9に寄る

# LINE / アプリ / グッズ確認

## LINE候補

確認サイズ：

```text
370x320
96x74
```

見ること：

- 顔が潰れない
- くちばしと足が見える
- m7らしい姿勢が残る
- コードネームを後載せする余白がある

## アプリ候補

見ること：

- カード内で大きすぎない
- 運指画像と並んでも強すぎない
- `Am7 / Dm7 / Em7` で同じ鳥として使える
- 音名違いのアクセントを後から載せても邪魔にならない

## グッズ候補

見ること：

- アクリルキーホルダーにしたとき、輪郭が単純
- ステッカーにしたとき、白い体が背景に埋もれない
- 刺繍にしたとき、細部を削っても夜雀感が残る

# 採用保留にする条件

以下が1つでも強い場合は、正式採用せず修正または再生成する。

- 黒い鳥に見える
- カラスに見える
- minor鳥の色違いに見える
- 星・月・装飾が多い
- 目が小さすぎる
- 足やくちばしが消える
- リアルな雀に寄りすぎる
- 1案の中に複数鳥がいる
- コード記号や文字が入っている
- LINE小サイズで形が崩れる
