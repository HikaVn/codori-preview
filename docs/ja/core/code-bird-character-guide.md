# Codori キャラクターデザインガイド

## このファイルについて

このファイルは、Codoriの鳥キャラクターをアプリ、LINEスタンプ、SNS、グッズへ展開するときの基本ルールをまとめる日本語正本です。

Codoriは、音楽理論をそのまま絵に置き換えるプロジェクトではありません。コードの感じを、覚えやすい白い鳥のアクション・表情・ポーズとして整理するプロジェクトです。

2026-05-27時点で、旧方針の「コード種類=鳥種」は撤回します。
本番では、元の白い鳥を主役にして、コード種類をアクション違いで表します。

新しい正本：

```text
docs/ja/core/white-bird-action-system.md
```

## 最重要ルール

- 本番キャラクター = 元の白い鳥
- コード種類 = 白い鳥のアクション違い + 小さなワンポイント形状
- 音名 / キーではアクション、表情、ワンポイント形状を変えず、色を変える
- 展開形やフォーム違いで別キャラを作らない
- テンションは小さなアクセントや空気感で扱う
- 鳥画像とウクレレ運指画像は分ける
- 小さく表示しても読めるシルエットを優先する

## 固定部分と暫定部分

### 固定する部分

以下をCodoriの中核ルールとして維持します。

```text
本番キャラクター = 元の白い鳥
コード種類 = 白い鳥のアクション違い + 小さなワンポイント形状
音名 / キー = コード名・運指画像・キー色
フォーム / 展開形 = 運指画像・ポーズ・学習状態
テンション = 小物・光・浮遊感・補助モチーフ
```

### 暫定として扱う部分

具体的なアクションデザインは、学習効果とIPのかわいさを見ながら更新できます。

現行のMajor / minor / 7 / add9の4鳥は、過去のMVP用採用版です。
本番では元の白い鳥のアクション差分へ置き換えます。

## アクション対応の正式候補

現フェーズでは、以下を正式候補として扱います。

| コード種類 | 表記例 | 白い鳥のアクション | 感情・役割 |
|---|---|---|---|
| Major | C, D, F | 安心して立つ | 明るい、安心、基準 |
| minor | Cm, Dm, Am | そっと寄り添う | 切ない、内向き、寄り添い |
| 7 | C7, G7, A7 | 次へ誘う | いたずら、前へ進みたがる、ブルージー |
| add9 | Cadd9, Dadd9 | きらっと見上げる | きらきら、青春、空気感 |
| M7 / maj7 | CM7, Cmaj7 | 透明にたたずむ | 透明感、上品、おしゃれ |
| m7 | Cm7, Am7 | グラサンでゆるく立つ | 夜、余韻、エモい、クール |
| mM7 | CmM7, Cm(maj7) | 不気味な目元で見つめる | サスペンス、犯人感、過酷な運命 |
| sus4 | Csus4, Gsus4 | Cと同じ丸目で空中に浮く | 浮遊、未解決、まだ着地しない |
| m7-5 | Cm7-5, Bm7-5 | 振り向きざまにちらっと見る | 頬のバッテン傷、ニヒル、不安定 |

## 共通シルエットルール

Codoriの鳥は、種類が違っても同じ世界の住人に見える必要があります。

共通して守ること：

- 丸く、やわらかい体型
- 大きめの顔
- 読みやすい目
- 小さなくちばし
- 小さな足
- 短く丸い羽
- 複雑すぎない頭ハネや尾
- 背景なしでも成立する形

避けること：

- 写実的な羽毛
- 細かすぎる模様
- 色だけでコード種類を分けること
- 服や小物でシルエットを隠すこと
- 文字がないと誰かわからないデザイン

## 音名 / キーの扱い

音名やキーが変わっても、鳥種、アクション、表情、基本ポーズは変えません。
キー違いは色で表します。

例：

- C, F, G は同じ安心アクション
- Cm, Dm, Am は同じ寄り添いアクション
- C7, G7, A7, D7 は同じ次へ誘うアクション

音名違いは以下で表現します。

- 大きく読みやすいコード名
- ウクレレ運指画像
- キーごとの色
- 小さなタグ
- 小さな光やアクセント
- アプリ内のセット名や学習文言

色違いは、頬、羽先、胸元の淡い影、頭上ハネ、小タグ、小さな光を中心に使います。
全身を強く塗り替えて別キャラに見える状態は避けます。

## 表情とポーズ

表情は、コードの感情を伝えるために使います。

- Major: 明るく安心する顔
- minor: そっと寄り添う顔
- 7: いたずらっぽく前へ進む顔
- add9: きらっと空気が広がる顔

ポーズは、同じ鳥の中の状態として扱います。フォームや展開形の違いを別キャラにしないため、ポーズは増やしすぎず、学習に必要な範囲で使います。

## 初期4アクションの扱い

初期4コードの意味と見せ方は、白い鳥のアクション差分として維持します。

詳細は以下を正とします。

```text
docs/ja/characters/initial-four-white-bird-action-decision.md
```

現時点の方針：

- 元の白い鳥を本番キャラクターとして使う
- Major / minor / 7 / add9は、白い鳥のアクション違いとして確定する
- A7 / D7などは、7アクションのキー展開として追加できる

## アプリでの注意

- 鳥、コード名、音、運指画像を同時に結びつける
- クイズは鳥を当てるだけにしない
- 再生ボタンは学習の入口として目立たせる
- 運指画像は鳥の体に描き込まない
- スマホ幅で鳥と運指画像が小さくなりすぎないようにする

## LINEスタンプでの注意

- 文字はコードネームのみ
- 日常あいさつ文は入れない
- コード名は大きく、Deep Blueを基本に読みやすくする
- 鳥は370x320実寸で大きく見える構図にする
- 96x74タブ画像でもつぶれないか確認する

## SNS・グッズでの注意

- SNSでは、鳥の感情とコードの感じが一目で伝わる構図にする
- グッズでは、細い線や小さすぎる小物を避ける
- アクリル、シール、缶バッジ、キーホルダーで成立する輪郭を優先する
- 正式グッズ化前に白黒シルエット確認を行う
