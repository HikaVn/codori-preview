# Codori ビジュアルスタイルガイド

## このファイルについて

このファイルは、
Codoriの「見た目の物理法則」を整理するためのガイド。

画像生成AI、
イラスト制作、
LINEスタンプ制作、
将来のアプリ化まで含めて、
絵柄を統一する目的を持つ。

---

# Codoriの基本方向

Codoriは：

- かわいい
- やわらかい
- 小さい
- 少し絵本っぽい
- 日本マスコット感
- 感情が伝わる

方向を目指す。

理論説明より、
キャラクター性を優先する。

# 顔

## 目

- 大きめ
- 感情が分かる
- 黒目主体
- ハイライト少なめ
- 白目は最小限
- 目の大きさは4鳥で揃える
- Cの平均目面積を基準に、他の鳥は±10%以内に収める
- 表情差よりも目サイズ差が出ないことを優先する

確認コマンド：

```sh
swift tools/check_character_eye_size.swift
```

# くちばし

- 小さい
- 丸め
- 三角すぎない
- 攻撃的にしない

---

# 羽

- 短い
- 丸い
- シンプル
- 指状に分けない
- 羽先の形は4鳥で揃える
- 元々のCの羽を基準に、自然な輪郭品質を最優先する
- 小さな丸い2山の割れを使う場合は、輪郭線そのものの凹みとして作る
- 内側に線を足して割れを表現しない
- 品質が保てない場合は、割れなし寄せを優先する
- 体や角度で隠れて見えない羽先は、無理に割れを見せない
- 7の上げ羽やadd9の流れ羽でも、先端だけ尖らせない
- 羽先をリアルな羽毛、ギザギザ、手指のようにしない

# 覚えやすさ優先の変化ルール

Codoriでは、学習者が混乱しないように、
見た目の変化を以下の順で使い分ける。

| 変わるもの | 見た目で変えるもの | 変えないもの |
|---|---|---|
| コード種類 | 鳥種、体型、表情、基本ポーズ | 音名ごとの別キャラ化 |
| 音名 / キー | コードネーム、キー色、小タグ、小さな光、控えめなアクセント | 鳥種、表情、基本シルエット |
| フォーム / voicing | 運指画像、必要に応じた小さなポーズ差 | 鳥種 |
| テンション | 小さなアクセサリ、星、浮遊感 | 複雑な衣装、大量装飾 |

最も重要なのは、
コード種類を鳥の違いとして覚えられること。

キー違いは色で表す。
ただし、同じMajorなのに別キャラに見えるほどの強い塗り替えは避ける。

---

## コード種類

コード種類ごとに、
ベースカラーを持つ。

例：

- Major → 黄色系
- minor → 青系
- add9 → 水色系

---

## キー

キー違いは：

- 頬
- 羽先
- 胸元の淡い影
- 頭上ハネ
- 小タグ
- 光
- 星
- 月
- オーラ

などの色で差を付ける。

全身を強く塗り替えるのではなく、
同じ鳥のキー色違いとして読める範囲にする。

コードネーム文字色は、原則として共通のDeep Blueにする。
音名ごとに文字色を変える場合も、キー色との可読性が保てる場面に限定する。

キー色の初期案は以下で管理する。

```text
docs/ja/characters/chord-expression-and-key-color-policy.md
```

# 文字とフォント

Codoriのアプリ内文字は、世界観に合わせて丸みのある書体を優先する。

基本方針：

- 丸ゴシック系を第一候補にする
- かわいさを優先しすぎて読みにくくしない
- コードネームは太く、Deep Blueで読みやすくする
- 本文はやさしいが、長文でも疲れにくい太さにする
- 文字間は詰めすぎない

アプリ用フォントスタック：

```css
"Hiragino Maru Gothic ProN",
"Hiragino Maru Gothic Pro",
"Zen Maru Gothic",
"M PLUS Rounded 1c",
"Kosugi Maru",
ui-rounded,
"Arial Rounded MT Bold",
"Hiragino Sans",
"Yu Gothic",
system-ui,
sans-serif
```

コードネーム用：

```css
"Arial Rounded MT Bold",
"Hiragino Maru Gothic ProN",
"Zen Maru Gothic",
"M PLUS Rounded 1c",
ui-rounded,
"Hiragino Sans",
system-ui,
sans-serif
```

注意：

- 外部Webフォントには現時点では依存しない
- フォント未インストール環境では近い丸みのあるフォントへフォールバックする
- LINEスタンプのコードネーム文字は引き続きDeep Blue + 太め丸文字を基準にする
