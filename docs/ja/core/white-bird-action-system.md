# Codori 白い鳥アクション方式

## このファイルについて

このファイルは、2026-05-27時点の新方針を記録する正本メモです。

以前の「コード種類ごとに鳥種を変える」方針は撤回します。
本番では、元の白い鳥をCodoriの主役として使い、コード種類は鳥種ではなくアクションと小さなワンポイントで表します。

## 結論

Codoriの本番方針は以下です。

```text
本番キャラクター = 元の白い鳥
コード種類 = 白い鳥のアクション違い + 小さなワンポイント形状
キー違い = 同じアクション、同じワンポイント形状の色違い
フォーム違い = 運指画像
```

重要：

- コード種類が変わっても、鳥種は変えない。
- 白い鳥を中心キャラクターとして固定する。
- コード種類は、表情、ポーズ、羽、目線、重心、小さな動き、ワンポイント形状で表す。
- キーが変わっても、アクションとワンポイント形状は変えない。
- キー違いは、ワンポイント色、頬、羽先、胸元影、小タグなどの色で表す。

## キー違いルール

キー違いでは、アクションとワンポイント形状を変えない。

例：

```text
C  / F  / G  = 安心して立つアクションとホームドットは同じ。色だけ違う。
Cm / Dm / Am = そっと寄り添うアクションと三日月は同じ。色だけ違う。
C7 / G7 / A7 = 次へ誘うアクションと矢印は同じ。色だけ違う。
```

色変更は以下に限定する。

- ワンポイント
- 頬
- 羽先
- 胸元の淡い影
- 頭上ハネ
- 小タグ
- 小さな光やアクセント

全身を強く塗り替えて、別キャラに見える状態は避ける。

## 現時点のアプリ対応

2026-05-29時点では、アプリにv7のアクション候補を反映している。

```text

```

ただし、v7は最終完成ではない。
ポーズ差はv6bより強くなったが、ポーズだけではコード種類が伝わりにくい。
次はv8として、ポーズに小さなワンポイントを足した候補を設計する。

正式アクション + ワンポイント画像を作ったら、以下のように差し替える。

```text

...
```

ただし、どの画像も同じ白い鳥のアクション差分として制作し、ワンポイントはコード種類を読むための最小補助に留める。
