# Codori 白い鳥アクション方式

## このファイルについて

このファイルは、2026-05-27時点の新方針を記録する正本メモです。

以前の「コード種類ごとに鳥種を変える」方針は撤回します。
本番では、元の白い鳥をCodoriの主役として使い、コード種類は鳥種ではなくアクション違いで表します。

## 結論

Codoriの本番方針は以下です。

```text
本番キャラクター = 元の白い鳥
コード種類 = 白い鳥のアクション違い
キー違い = 同じアクションの色違い
フォーム違い = 運指画像
```

重要：

- コード種類が変わっても、鳥種は変えない。
- 白い鳥を中心キャラクターとして固定する。
- コード種類は、表情、ポーズ、羽、目線、重心、小さな動きで表す。
- キーが変わっても、アクションは変えない。
- キー違いは、頬、羽先、胸元影、小タグなどの色で表す。

|---|---|---|
| コード種類 | 鳥種で分ける | 白い鳥のアクションで分ける |
| Major | シマエナガ方向 | 白い鳥の安心アクション |
| minor | 文鳥方向 | 白い鳥の寄り添いアクション |
| 7 | カラス方向 | 白い鳥の次へ誘うアクション |
| add9 | 青い小鳥方向 | 白い鳥の見上げるアクション |
| m7 | 夜雀として別鳥種化 | 白い鳥のほどける夜アクション |
| maj7 | 白鳥として別鳥種化 | 白い鳥の透明で上品なアクション |
| mM7 | 黒鳥として別鳥種化 | 白い鳥の宿命を見つめるアクション |

## キー違いルール

キー違いでは、アクションを変えない。

例：

```text
C  / F  / G  = 安心して立つアクションは同じ。色だけ違う。
Cm / Dm / Am = そっと寄り添うアクションは同じ。色だけ違う。
C7 / G7 / A7 = 次へ誘うアクションは同じ。色だけ違う。
```

色変更は以下に限定する。

- 頬
- 羽先
- 胸元の淡い影
- 頭上ハネ
- 小タグ
- 小さな光やアクセント

全身を強く塗り替えて、別キャラに見える状態は避ける。

## ボツにするもの

以下は本番方針から外す。

- m7を夜雀として新鳥種化する案
- maj7を白鳥として新鳥種化する案
- mM7を黒鳥として新鳥種化する案
- sus4をペンギンとして新鳥種化する案
- dimやm7-5をフクロウとして新鳥種化する案
- augを極楽鳥として新鳥種化する案

これらは過去検討として残してよいが、本番正本にはしない。

## 現時点のアプリ対応

新しいアクション別画像が揃うまでは、アプリでは元の白い鳥を共通表示にする。

```text
assets/approved/characters/major.png
```

正式アクション画像を作ったら、以下のように差し替える。

```text
assets/approved/characters/action-major.png
assets/approved/characters/action-minor.png
assets/approved/characters/action-7.png
assets/approved/characters/action-add9.png
...
```

ただし、どの画像も同じ白い鳥のアクション差分として制作する。
