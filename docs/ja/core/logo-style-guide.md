# Codori ロゴ初期デザイン方針

## このファイルについて

このファイルは、Codoriロゴの初期方針をまとめるための正本メモです。

現時点の目的は、正式ロゴを確定することではなく、アプリ、LINEスタンプ、SNS、グッズへ展開しやすいロゴの方向性を決めることです。

---

# ロゴの基本方針

Codoriのロゴは、ウクレレコード記憶アプリとしての読みやすさと、白い小鳥キャラクターIPとしてのかわいさを両立させます。

優先する印象：

- やさしい
- 覚えやすい
- 音楽に近いが、理論っぽすぎない
- 小さく表示しても読める
- 白いCodori世界観とDeep Blue文字がつながる

避ける印象：

- 写実的な鳥ロゴ
- 複雑な譜面・五線・音符だらけのロゴ
- 既存4鳥の再デザインに見えるロゴ
- 色数が多すぎるロゴ
- 小サイズで読めない手書き文字

---

# ロゴ方向性3案

## 案A: 文字ロゴ中心

`Codori`の文字を主役にする方向です。

特徴：

- アプリ名として読みやすい
- SNSアイコン以外の場所で使いやすい
- 教材・アプリの信頼感を出しやすい

注意：

- 文字だけだとキャラクターIP感が弱い
- 小鳥の世界観が伝わりにくい

向いている用途：

- アプリヘッダー
- Webサイト
- 教材PDF
- ストア説明画像

---

## 案B: 文字ロゴ + 小鳥アイコン

`Codori`の文字と、簡略化した白い小鳥アイコンを組み合わせる方向です。

特徴：

- Codoriの名前とキャラクターIP感を同時に伝えられる
- アイコン部分だけをSNSやアプリアイコンへ展開できる
- アプリ、LINE、グッズにまたがって使いやすい

注意：

- 小鳥アイコンは正式4鳥そのものではなく、ロゴ用の共通シンボルとして扱う
- 鳥のディテールを増やしすぎない

向いている用途：

- アプリ起動画面
- アプリヘッダー
- LINEスタンプのメイン画像
- SNSプロフィール
- ステッカー、缶バッジ、タグ

初期推奨：

```text
案Bを初期本命とする。
```

理由：

```text
Codoriは学習アプリであり、同時に鳥キャラクターIPでもあるため。
文字だけではIP性が弱く、鳥だけでは名前が伝わりにくい。
```

---

## 案C: 音の巣・星アクセント型

文字ロゴに、小さな星、音の粒、やわらかい光を添える方向です。

特徴：

- add9のような空気感や、音が広がる感じを出せる
- かわいく軽い印象にしやすい

注意：

- 音符や星を増やすと幼くなりすぎる
- 音楽教室ロゴのように見えすぎないようにする
- 初期4鳥よりロゴ装飾が目立たないようにする

向いている用途：

- SNS投稿テンプレート
- グッズのワンポイント
- アプリ内の達成演出

# 色ルール

色は増やしすぎず、Deep Blueと白鳥世界観を中心にします。

```text
Deep Blue: #1e5aa8
Ink: #1f2933
Soft Blue: #eaf2fb
Paper: #fbfcfd
Gold Accent: #d89b2b
```

使い分け：

- Deep Blue: `Codori`文字の主色
- Ink: 小鳥の輪郭、目、くちばし
- Soft Blue: 背景のやわらかい面
- Paper: 白背景
- Gold Accent: 星や音の小さなアクセント

注意：

- ロゴではキー別カラーを展開しない
- 色違いロゴを大量に作らない
- Gold Accentは小さく使う
- グラデーション主体にしない

---

# 形のルール

小鳥アイコン：

- 白い丸い体
- 黒い輪郭
- 小さな目
- くちばしは小さくシンプル
- 頭のハネは2本以内で、冠のように大きくしない
- 足はカールさせすぎず、必要ならロゴでは省略する
- 羽・足は小さく、シルエットを崩さない

文字：

- 丸みのある太めの書体
- 小サイズでも読める
- 文字間は詰めすぎない
- 手書き風にしすぎない
- `C / o / d / r / i`が判別できることを優先する
- アプリ内文字も丸ゴシック系に寄せ、ロゴだけが浮かないようにする

# 用途別の条件

## アプリ

- ヘッダーに置いても邪魔にならない
- スマホ幅で`Codori`が読める
- 小鳥アイコン単体でもアプリアイコン候補にできる
- 学習画面の正式4鳥より目立ちすぎない
- アプリヘッダーでは英字サブコピーを入れず、`Codori`ロゴと日本語タイトルを分けて表示する

## LINE

- メイン画像やプロフィール的な見え方で使える
- スタンプ本体のコード名と競合しない
- タブ画像では、文字ロゴよりアイコン単体を優先する

## SNS

- 丸アイコン、正方形アイコンで成立する
- 投稿画像の左上や末尾に小さく置ける
- 白背景でも淡色背景でも見える

## グッズ

- 単色化しても破綻しにくい
- 缶バッジ、ステッカー、タグで読める
- 細すぎる線や小さすぎる装飾を避ける

---

# NG差分

作らない方向：

- 既存4鳥をロゴ内に全員入れる
- コード進行や運指図をロゴに入れる
- 音符・五線を主役にする
- 鳥を写実的にする
- 色違いロゴをキー別に量産する
- ロゴ内でコード種類の差を表現する

理由：

```text
ロゴはCodori全体の入口であり、コードごとの差分を説明する場所ではないため。
コード種類の違いは正式4鳥、音名の違いはコードネームや小さなアクセントで表現する。
```

# 現時点の判断

```text
初期本命: 案B 文字ロゴ + 小鳥アイコン

現フェーズ決定: rough-04

状態: rough-04を現フェーズのロゴとして固定

```

判断理由：

- アプリヘッダーで`Codori`が読みやすい
- Deep Blueと白鳥世界観がつながって見える

- 足を省略したことで、アイコンとしてすっきりした
- 48pxでも顔と白鳥感が残る
