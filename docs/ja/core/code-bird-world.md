# Codori 世界観ガイド

## このファイルについて

Codoriは、ウクレレコードをかわいい鳥キャラクターで覚えるための学習アプリ兼キャラクターIPです。

音楽理論は大切ですが、Codoriの入口は「この子かわいい」「この音の感じを覚えられそう」という感情です。

## 名前の考え方

Codoriは、コードの響きと小鳥のかわいさをつなぐ名前です。

- Chord: musical harmony and chord feeling
- Dori: a soft bird-like Japanese sound
- Codori: little birds that help people remember musical feelings

## 世界観の基本

Codoriの世界では、コードはただの記号ではなく、響きの気分を持った小鳥として現れます。

コードを覚えるときに見るもの：

- 鳥の種類
- 鳥の表情
- コード名
- ウクレレ運指画像
- 音
- そのコードの感情

これらが少しずつつながって、フォーム暗記だけに頼らない学習になります。

## 世界のトーン

Codoriらしさ：

- あたたかい
- やさしい
- かわいい
- Musical but approachable
- 初心者に近い
- 集めたくなる
- 少し物語がある

避けること：

- 理論書の図解だけに見えること
- 音符や記号で画面が混みすぎること
- 色数が多すぎること
- 暗く怖いキャラクターに寄りすぎること
- 鳥のかわいさより説明が勝つこと

## 舞台

Codoriたちは、やわらかい音の庭に住んでいます。

現フェーズでは、舞台名は以下を優先候補とします。

```text
The Harmony Garden
```

補助候補：

- The Melody Grove
- The Kodori Forest

この舞台名は、画像の背景やSNS文言に使うための補助設定です。アプリやLINEでは、鳥そのものの見やすさを優先します。

## 繰り返し使える場所

- Staff Line Meadow: 五線が草原のように見える場所
- Rest Nest: 休符のように落ち着く場所
- Melody Branch: 小鳥が音を鳴らす枝
- Circle Pond: コードの仲間が集まる池
- Sticker Stage: LINEスタンプ用のすっきりした舞台

これらは世界観の助けであり、必須背景ではありません。

## キャラクターの役割

Codoriの鳥は、コード種類の感情を表します。

表現に使うもの：

- 体型
- 鳥種
- 目
- くちばし
- 羽の動き
- ポーズ
- 小さなアクセント
- コード名
- 運指画像

鳥は文字がなくてもかわいく成立し、文字があるとコード学習につながる状態を目指します。

## アプリでの世界観

アプリでは、Codoriは先生というより、横にいて一緒に覚える小鳥です。

文言は硬くしすぎず、次のような方向にします。

- 「正解 / 不正解」より「だんだん聞こえてきた」
- 「鳥がつながってきた」より「感情がつながってきた」
- 「テスト」より「音をさがす」
- 「理論」より「響きの感じ」

## LINEスタンプでの世界観

LINEスタンプでは、日常あいさつではなくコードネームを大きく載せます。

目的：

- コード名を覚える
- 鳥と音の感じを結びつける
- サウンド付きスタンプへ展開しやすくする

## グッズ・SNSでの世界観

グッズやSNSでは、鳥だけでもかわいいことを優先します。

ただし、Codoriらしさを失わないために、コード名・音の感じ・小さな音楽モチーフのどれかを残します。
