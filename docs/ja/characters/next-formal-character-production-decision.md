# Codori 次期正式キャラクター制作判断

## このファイルについて

2026-05-27時点で、このファイルの「次期正式キャラクターを別鳥種で作る」方針はボツです。
本番では、元の白い鳥のアクション差分でコード種類を表します。

新しい正本：

```text
docs/ja/core/white-bird-action-system.md
```

このファイルは、初期4鳥の次に作る正式キャラクター候補を比較し、画像生成前の判断材料を整理するためのメモです。

前提：

- 初期4鳥 `Major / minor / 7 / add9` は正式運用中。
- アプリMVPと練習モードは一旦十分。
- 次は本番キャラクターIP拡張を優先する。
- `コード種類 = 鳥種` の旧方針は維持しない。
- 音名 / キー違いではアクション、表情、基本ポーズを変えない。
- キー違いは色で表す。
- 新キャラは大量生成せず、候補を絞って作る。

# 推奨結論

次に正式キャラクターとして制作する候補は、以下の2種類を推奨する。

```text
第1候補: m7 / 夜雀
第2候補: maj7 / 白鳥
```

理由：

- すでにアプリ内に `m7の夜` と Stage 3があり、学習上の使い道が明確。
- `m7` は minorとの差を作りやすく、初心者にも「切ない」から「ほどける」への違いを説明しやすい。
- `maj7` は Major / add9との差が課題だが、白鳥シルエットを使えばIPとして強い。
- `m7` と `maj7` をセットで作ると、Stage 3「夜のC」の世界観が固まりやすい。
- LINE、SNS、グッズでも「夜雀」と「白鳥」はキャラ単体の印象が強い。

今回は、`sus4 / m7-5 / dim / aug` は次フェーズ候補として残す。

# 既存4鳥との見分け方

## m7 / 夜雀

既存4鳥との差：

- minorより少しリラックスしている。
- 7鳥ほど前へ進まない。
- add9ほど上向き・星感を出さない。
- Majorほど正面で安定させない。

方向性：

- 小さく丸い夜の鳥。
- 眠そう、でも暗すぎない目。
- 羽は体に近く、肩の力が抜けた姿勢。
- 小さな夜色アクセントやキー色は可。ただし全身色を強く変えすぎない。

NG：

- 黒い鳥にしすぎる。
- minor鳥より悲しそうにする。
- 7鳥のように前傾・いたずら顔にする。
- 星や光を増やしてadd9に寄せる。

## maj7 / 白鳥

既存4鳥との差：

- Majorより上品で静か。
- add9より大人っぽく、きらきらを抑える。
- minorより沈まない。
- 7鳥ほど動かない。

方向性：

- 白鳥らしい首の流れを、マスコットとして極端に簡略化する。
- 首を長くしすぎず、小サイズでも顔が読める。
- 透明感、静かな光、上品な目線。
- 白い体を基準にし、Deep Blueや淡い青の小アクセントで十分。

NG：

- リアルな白鳥にする。
- 首を長くしすぎてシルエットが複雑になる。
- add9の星モチーフと混ざる。
- ロゴの白鳥アイコンと同一デザインにする。

# 次に画像生成する数

大量生成はしない。

推奨：

```text
m7 / 夜雀: 6〜8案
maj7 / 白鳥: 6〜8案
```

最初は1枚の中に複数案を詰めるより、1案ずつ独立して生成する。
採用候補は各コード種類から2〜3案に絞り、既存4鳥と並べて確認する。

---

# 採用前チェック

- 初期4鳥と並べて、コード種類差が一目で分かるか。
- 小さくしても目、くちばし、足、基本シルエットが読めるか。
- LINE 370x320と96x74タブで潰れないか。
- アプリカード内で鳥、コード名、運指画像と並んでも強すぎないか。
- 音名違いのバリエーションを作らなくても成立するか。
- グッズ化時に、刺繍・アクリル・ステッカーで形が残るか。
