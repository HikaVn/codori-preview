# Codori m7 / 夜雀 画像生成プロンプト

## このファイルについて

このファイルは、`m7 / 夜雀`の正式候補画像を作るための画像生成プロンプト集です。

目的は、`minor`鳥との差を保ちながら、`m7`の「夜にほどける余韻」を1枚絵で読める候補を作ることです。

## 結論

最初の生成は8案とする。

```text
候補01: 基準夜雀
候補02: 伏し目の余韻
候補03: 小さく座る夜雀
候補04: 横向きの帰り道
候補05: 羽をほどく夜雀
候補06: 淡い月影
候補07: 眠る直前ではない半目
候補08: LINEスタンプ向け強シルエット
```

採用判断では、候補01、02、08を優先して見る。

## 共通プロンプト

各候補の先頭に、以下の共通指定を入れる。

```text
Codori style cute mascot bird character for a ukulele chord learning app,
small round bird, simple silhouette, 1.5 to 2 head tall, soft picture-book style,
Japanese mascot feel, thick clean outline, rounded tiny beak, short rounded wings,
large gentle dark eyes with small highlights, warm and cute, readable at 96px,
transparent background, centered full body, no text, no chord diagram
```

## 共通ネガティブプロンプト


## 採用チェック表

生成後は、各候補を以下の基準で見る。

| 観点 | 合格条件 |
|---|---|
| m7らしさ | 夜、余韻、ほどける感じが出ている |
| minorとの差 | minorより悲しすぎず、内向きすぎない |
| mM7との差 | 黒鳥、宿命、過酷な運命に見えない |
| add9との差 | 星や光が主役になっていない |
| 7との差 | 前傾、いたずら顔、片羽上げに見えない |
| 小サイズ | 96pxで目、くちばし、丸い体が読める |
| LINE適性 | 370x320でコード名と並べても強すぎない |
| キー展開 | 色違いにしても同じ夜雀として読める |

## 初回生成後の推奨判断

初回生成後は、以下の順で見る。

```text
1. 候補08で小サイズ耐性を見る。
2. 候補01でm7の基準表情を見る。
3. 候補02でminorとの差を見る。
4. 候補03または05で姿勢差を見る。
5. 候補06は装飾が強すぎる場合は不採用にする。
```

採用候補は2〜3案に絞り、初期4鳥と横並びにしてから判断する。
