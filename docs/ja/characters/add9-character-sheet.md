# 羽

- 短く丸い
- 片側に流れを出してもよい
- 星や文字を邪魔しない
- 7の片羽上げと混ざらない
- 羽先は元々のCの丸い形に揃える
- 割れを入れる場合は、見えている左右のバランスが崩れないようにする
- 内側に線を足して割れを表現しない
- 体の後ろや角度で見えない羽先は、無理に割れを見せない
- 流れを出しても、先端は尖らせず丸く閉じる
- 7との差は羽先ではなく、上向き姿勢と星アクセントで出す

# キー表現

音名違いは、鳥種、表情、基本ポーズでは表現しない。

`Cadd9`, `Fadd9`, `Gadd9` などは同じadd9鳥を使い、
キー色、コードネーム、運指画像、小タグ、小さな光で区別する。

add9鳥の見上げる表情と広がる感じは、キーが変わっても固定する。

# LINEスタンプ時

# アプリ時

- CからCadd9へ変わったときの「広がり」を覚える
- 音の空気感と見上げる鳥を結びつける
- 運指画像とは重ねず、並べて表示する

# SNS・グッズ時

- 星は小さすぎると消えるため、印刷サイズに合わせて少し太らせる
- 白い体が背景に溶ける場合は外フチで支える
- ぬいぐるみ化では星を別パーツにせず、タグや刺繍で表現してもよい
