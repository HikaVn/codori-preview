# Codori 残りコード 白い鳥アクションレビュー 2026-05-27

## このファイルについて

このファイルは、LINEスタンプ展開へ進む前に、初期4コード以外のコード種類を元の白い鳥のアクション差分として確認したレビューです。

対象は以下です。

```text
m7 / maj7 / mM7 / sus4
m7-5 / dim / aug
```

## 結論

残り7コードも、別鳥種ではなく白い鳥のアクション差分として進められる。

v2を正式候補ベースとして扱う。

ただし、mM7は表情が少し強いため、正式採用前に眉のような線を弱める。

## m7 / maj7 / mM7 / sus4 v2評価

| コード種類 | 評価 | 理由 |
|---|---|---|
| m7 | 良い | 半目寄りで力が抜けており、minorより夜っぽい余韻が出ている |
| maj7 | 良い | 背筋が伸び、静かにたたずむ感じがある。白鳥化していない |
| mM7 | 要調整 | 宿命を見つめる方向は出ているが、眉のような線で少し悪役寄りに見える |
| sus4 | 改善 | 片足上げで保留感が読める。正式化時は足の形を少し自然にする |

## m7-5 / dim / aug v2評価

| コード種類 | 評価 | 理由 |
|---|---|---|
| m7-5 | 良い | 体の傾きで少し揺れる不安定さが読める。怖くなりすぎていない |
| dim | 良い | きゅっと固まる感じが明確で、ホラー化していない |
| aug | 改善 | ふわっと驚く方向は分かる。正式化時は口と羽の開き方を少し抑える |

## 正式化時の修正方針

- すべて元の白い鳥として、体型、頭上ハネ、くちばし、足の基本形を揃える。
- mM7は黒鳥化せず、暗い色ではなく目線と姿勢で「ミステリーかつ過酷な運命」を表す。
- m7-5、dim、augは不思議系として読ませるが、怖さや派手さを強くしすぎない。
- 画像は背景透過の単体素材に分け、96pxでも確認する。
