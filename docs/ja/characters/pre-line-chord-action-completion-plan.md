# Codori LINE前 コードアクション完成計画

## このファイルについて

このファイルは、LINEスタンプ展開へ進む前に、コード種類ごとの白い鳥アクションを完成させるための作業計画です。

## 結論

LINE展開は後回しにする。
先に、コード種類ごとの白い鳥アクションを完成させる。

優先順は以下とする。

```text
Step 1: 初期4コード
Major / minor / 7 / add9

Step 2: 夜と透明感のコード
m7 / maj7 / mM7 / sus4

Step 3: 不思議なコード
m7-5 / dim / aug

Step 4: キー違い12色

Step 5: LINEスタンプ派生
```

## 完成条件

コードアクションが完成したと言える条件は以下です。

- 同じ白い鳥に見える。
- コード種類ごとのアクション差が読める。
- キー違いではアクションを変えず、色だけ変えられる。
- 96pxでも表情とポーズが読める。
- アプリカードでコード名・運指画像と並べても強すぎない。
- LINE化しても破綻しないが、LINE専用最適化はまだしない。

## Step 2の制作方針

```text
m7   = 力が抜ける。minorよりやわらかく、眠りすぎない。
maj7 = 静かに遠くを見る。add9より落ち着き、白鳥化しない。
mM7  = 過酷な運命を見つめる。黒鳥化せず、静かな覚悟で出す。
sus4 = まだ待っている。片足または体を少し浮かせ、保留感を出す。
```

## Step 3の制作方針

```text
m7-5 = 少し揺れる。怖くせず、不安定さを小さな傾きで出す。
dim  = きゅっと固まる。不思議だがホラーにしない。
aug  = ふわっと驚く。夢っぽいが、派手にしすぎない。
```

## LINEを後回しにする理由

LINEは最終的に必要だが、先にコード種類の見分け方を固める。

理由：

- LINEサイズに最適化してからコード体系を変えると、作り直しが増える。
- コード種類のアクションが揃うと、LINE、アプリ、SNS、グッズへ一貫して展開できる。
- キー違い12色も、アクションが固まってから展開した方が安全。
