# Codori コード種類別表情・キー色ポリシー

## このファイルについて

このファイルは、Codoriの鳥キャラクターについて、
コード種類ごとのアクションと、キー違いの色表現を固定するための正本メモです。

## 結論

Codoriでは、以下を固定方針とします。

```text
本番キャラクター = 元の白い鳥
コード種類 = 白い鳥のアクション・表情・基本ポーズ・小さなワンポイント形状
キー違い = 同じアクション、同じワンポイント形状の色違い
フォーム違い = 運指画像
```

アクションはコード種類の記憶に使います。
ワンポイントは、ポーズだけでは伝わりにくいコード種類を補助するために使います。
キー違いは、同じアクション、同じワンポイント形状の色違いとして扱います。

ただし、コード種類が変わっても鳥種は変えません。
キー違いでは、アクション、表情、基本シルエットは変えません。

## 固定ルール

- 同じコード種類では、白い鳥のアクションと表情を固定する。
- キーが変わる場合は、色で違いを出す。
- 色違いにしても、同じ白い鳥だと分かる範囲にする。
- 目、くちばし、足、基本ポーズはキーで変えない。
- フォーム違いは、鳥ではなく運指画像で扱う。

例：

```text
C  / F  / G  = 安心アクション。動きは同じ。キー色だけ変える。
Cm / Dm / Am = 寄り添いアクション。動きは同じ。キー色だけ変える。
C7 / G7 / A7 = 次へ誘うアクション。動きは同じ。キー色だけ変える。
```

## 表情の使い分け

### Major

「帰ってこられる場所」を表す。
目はやさしく、口元はごく小さく笑う。
テンションを上げすぎず、Codori全体の基準にする。

### minor

「静かに寄り添う」を表す。
悲しすぎる顔、泣き顔、暗い顔にはしない。
Majorとの差は、伏し目と内向きの姿勢で出す。

### 7

「次へ行こう」を表す。
いたずらっぽさは出すが、怒り顔や悪役顔にしない。
表情と片羽上げで、前へ進む感じを固定する。

### add9

「空気が広がる」を表す。
見上げる目線、澄んだ目、軽い微笑みを基本にする。
星や光に頼りすぎず、顔だけでも広がりを読めるようにする。

### m7

「minorよりほどける夜の余韻」を表す。
暗さではなく、力が抜ける感じを優先する。
minorより少し大人っぽく、やわらかくする。

### maj7

「透明で上品」を表す。
add9のきらきら感とは分け、落ち着いた美しさにする。
派手な表情ではなく、目線と姿勢で差を出す。

### mM7

「ミステリーかつ過酷な運命」を表す。
minorの静けさに、maj7の張りつめた光が入る音として扱う。
悲しいだけ、怖いだけにはせず、避けられない運命を静かに見つめる顔にする。

m7のほどける夜、maj7の透明な上品さ、dimの不思議さと混ざりやすい。
そのため、mM7は「やわらかさ」よりも「覚悟」と「緊張した美しさ」を優先する。

### sus4

「まだ着地しない」を表す。
不安ではなく、保留、待つ、浮く感じにする。
7のように前へ急がせず、Majorへ戻る直前の空気を持たせる。

### m7-5

「少し不安定で、次へ流れる」を表す。
怖さよりも、揺れや緊張感を優先する。
dimと混ざりやすいため、細さと都会的な目元で分ける。

### dim

「きゅっとしたミステリー」を表す。
怖い、ホラー、悪役にはしない。
小さくまとまった表情で、不思議さを出す。

### aug

「夢みたいにふくらむ」を表す。
不思議さ、驚き、浮遊感を持たせる。
派手すぎる極楽鳥ではなく、Codoriの丸くやさしい世界に寄せる。

## キー色ルール

キー違いは、色で表します。

ただし、色変更は次の範囲を基本にします。

- 頬
- 羽先
- 胸元の淡い影
- 頭上ハネ
- 小タグ
- 小さな光やアクセント

全身を強く塗り替えて、別キャラに見える状態は避けます。
学習上は「同じ鳥のキー色違い」と分かることを優先します。

## NG

- キーごとに表情を変える。
- キーごとに鳥種を変える。
- コード種類ごとに別鳥種を増やす。
- キーごとにシルエットを変える。
- コード種類の違いを色だけで表す。
- 12キー色を強くしすぎて、同じ白い鳥として読めなくなる。
