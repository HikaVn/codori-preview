# Codori 白い鳥ワンポイント補助設計

## 結論

ポーズだけではコード種類の差が伝わりにくいため、次の正式候補は「白い鳥のポーズ + 小さなワンポイント」で設計する。

ワンポイントは、鳥を別キャラ化する飾りではなく、コード種類を読むための最小補助記号として扱う。

## 役割分担

```text
鳥本体 = 元の白い鳥
コード種類 = ポーズ + ワンポイント形状
キー違い = ワンポイント色、頬、羽先、背景チップなどの色
フォーム違い = 運指画像
```

重要：

- ワンポイントの形はコード種類で固定する。
- キーが変わっても、ワンポイントの形と位置は変えない。
- キー違いは色だけで表す。
- 鳥の顔、体型、基本ポーズをワンポイントで隠さない。

## ワンポイント共通ルール

- 1コード種類につき、ワンポイントは原則1つ。
- 鳥本体に着せない。衣装、帽子、リボン、持ち物にはしない。
- 鳥の外側、または足元近くに小さく置く。
- 面積は鳥本体の5〜10%程度に抑える。
- 線幅は鳥の輪郭より少し細くする。
- 96px表示で形が潰れる場合は不採用。
- 音符、五線、派手な魔法エフェクトは避ける。
- 文字、コード記号、調号そのものは入れない。

## コード種類別ワンポイント案

| コード種類 | ポーズ | ワンポイント | 意味 | 位置 |
|---|---|---|---|---|
| Major | 安定して立つ | 小さな丸いホームドット | 安心、帰る場所 | 足元中央 |
| minor | 羽を内側へ寄せる | 内向きの小さな三日月 | 静けさ、内側へ向く | 左下 |
| 7 | 片羽を上げる | 小さな矢印または山形 | 次へ進む、解決へ向かう | 上げた羽の先 |
| add9 | 上を見る | 小さな一粒のきらめき | 空気が広がる、軽さ | 目線の先 |
| m7 | 力を抜く | やわらかい小さな輪 | 余韻、ほどける | 足元横 |
| maj7 | 遠くを見る | 透明な小ダイヤ | 透明感、上品さ | 視線の先 |
| mM7 | 横向きに張る | 細い斜めの小片 | 宿命、静かな覚悟 | 背後または右上 |
| sus4 | 片足を浮かせる | 浮いた小点 | 未解決、まだ着地しない | 浮いた足の下 |
| m7-5 | 斜めに傾く | 傾いた小ダイヤ | 揺れ、不安定 | 傾き側の下 |
| dim | 小さく固まる | きゅっと縮んだ小リング | 緊張、収縮 | 足元中央 |

## 採用候補と保留候補

最初のv8では、以下を優先する。

採用候補：

- Major: ホームドット
- minor: 小さな三日月
- 7: 小さな矢印
- add9: 一粒のきらめき
- mM7: 細い斜めの小片
- sus4: 浮いた小点
- dim: 縮んだ小リング
- aug: 広がる小リング

要確認：

- m7の輪とmaj7の小ダイヤが、96pxで十分に違って見えるか。
- m7-5の傾いた小ダイヤとmaj7の小ダイヤが混同しないか。
- dimの小リングとaugの広がるリングが、サイズ差で区別できるか。

## キー色との関係

キー違いはワンポイントの色へ反映する。

例：

```text
Cmaj7 / Fmaj7 / Amaj7 = 小ダイヤの形は同じ。色だけキー色に変える。
C7 / G7 / A7 = 矢印の形は同じ。色だけキー色に変える。
CmM7 / FmM7 = 斜め小片の形は同じ。色だけキー色に変える。
```

ただし、色だけに頼らない。
コード種類は形とポーズで読み、キーは色で読む。

## v8制作フロー

1. ワンポイントだけの白黒ラフ表を作る。完了。
2. 11コード種類のワンポイント形状を固定する。初期案として完了。
3. v7ポーズにワンポイントを追加したv8候補をアプリ上で重ねる。完了。
4. 96px縮小シートで、形が読めるか確認する。
5. アプリのカード、聞き比べ、音あてで表示確認する。一部完了。
6. キー色を当てたとき、コード種類とキー違いが混ざらないか確認する。
7. 正式候補に昇格するか、ワンポイント形状を再調整する。

実装メモ：

- 後乗せワンポイントは、鳥の世界観から浮きやすいため本番候補から外す。
- IMAGEGENで白い鳥とワンポイントを一緒に生成した統合版を`assets/app/characters/action-candidate-integrated-v1/`に置く。
- `app/main.js`の`ACTION_CHARACTER_ASSETS`で統合版の鳥画像を参照する。
- キー色はカード枠、チップ、背景へ反映し、鳥のアクションとワンポイントの関係はコード種類ごとに固定する。
