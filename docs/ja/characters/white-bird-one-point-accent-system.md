# Codori 白い鳥ワンポイント補助設計

## 結論

ポーズだけではコード種類の差が伝わりにくいため、次の正式候補は「白い鳥のポーズ + 小さなワンポイント」で設計する。

ワンポイントは、鳥を別キャラ化する飾りではなく、コード種類を読むための最小補助記号として扱う。

## 役割分担

```text
鳥本体 = 元の白い鳥
コード種類 = ポーズ + ワンポイント形状
キー違い = ワンポイント色、頬、羽先、背景チップなどの色
フォーム違い = 運指画像
```

重要：

- ワンポイントの形はコード種類で固定する。
- キーが変わっても、ワンポイントの形と位置は変えない。
- キー違いは色だけで表す。
- 鳥の顔、体型、基本ポーズをワンポイントで隠さない。

## ワンポイント共通ルール

- 1コード種類につき、ワンポイントは原則1つ。
- 鳥本体に着せない。衣装、帽子、リボン、持ち物にはしない。
- 鳥の外側、または足元近くに小さく置く。
- 面積は鳥本体の5〜10%程度に抑える。
- 線幅は鳥の輪郭より少し細くする。
- 96px表示で形が潰れる場合は不採用。
- 音符、五線、派手な魔法エフェクトは避ける。
- 文字、コード記号、調号そのものは入れない。

## コード種類別ワンポイント案

| コード種類 | ポーズ | ワンポイント | 意味 | 位置 |
|---|---|---|---|---|
| Major | 安定して立つ | 小さな丸いホームドット | 安心、帰る場所 | 足元中央 |
| minor | 悲しい顔で羽を寄せる | 割れたハート | 悲しさ、少し胸が痛む感じ | 顔の横 |
| 7 | 胸を張る | 小さなキラッ | ドヤっと決まる、少しにやっとする | 顔の横 |
| add9 | うつろに上を見る | 水色の小さな星 | 空気が抜ける、軽さ | 目線の先 |
| m7 | グラサンでゆるく立つ | 黒いサングラス | 余韻、ほどける、クール | 目元 |
| maj7 | 胸で羽を組み十字架を見つめる | 小さな十字架 | 透明感、上品さ、静かな憧れ | 視線の先 |
| mM7 | 不気味な目元で見つめる | 稲妻または鋭い小片 | サスペンス、犯人感、過酷な運命 | 背後または右上 |
| sus4 | Cと同じ丸目で空中に浮く | 浮いた小点 | 未解決、まだ着地しない | 体のまわり |

## 採用候補と保留候補

最初のv8では、以下を優先する。

採用候補：

- Major: ホームドット
- minor: 割れたハート
- 7: ドヤっとしたキラッ
- add9: 水色の小さな星
- mM7: 不気味な目元と稲妻
- sus4: 浮いた小点
- m7-5: 頬のバッテン傷
- dim: コウモリ羽
- aug: 広がる小リング

要確認：

- m7のグラサンとmaj7の小さな十字架が、96pxで十分に違って見えるか。
- m7-5の頬のバッテン傷が、96pxで傷として読めるか。
- dimのコウモリ羽とmM7の稲妻が、96pxで別の印象として読めるか。

## キー色との関係

キー違いはワンポイントの色へ反映する。

例：

```text
Cmaj7 / Fmaj7 / Amaj7 = 小さな十字架の形は同じ。色だけキー色に変える。
C7 / G7 / A7 = ドヤっとしたキラッの形は同じ。色だけキー色に変える。
CmM7 / FmM7 = 斜め小片の形は同じ。色だけキー色に変える。
```

ただし、色だけに頼らない。
コード種類は形とポーズで読み、キーは色で読む。

## v8制作フロー

1. ワンポイントだけの白黒ラフ表を作る。完了。
2. 11コード種類のワンポイント形状を固定する。初期案として完了。
3. v7ポーズにワンポイントを追加したv8候補をアプリ上で重ねる。完了。
4. 96px縮小シートで、形が読めるか確認する。
5. アプリのカード、聞き比べ、音あてで表示確認する。一部完了。
6. キー色を当てたとき、コード種類とキー違いが混ざらないか確認する。
7. 正式候補に昇格するか、ワンポイント形状を再調整する。

実装メモ：

- 後乗せワンポイントは、鳥の世界観から浮きやすいため本番候補から外す。
- IMAGEGENで白い鳥の表情差を強めた統合版を`assets/app/characters/action-candidate-integrated-v3/`に置く。
- `app/main.js`の`ACTION_CHARACTER_ASSETS`で統合版の鳥画像を参照する。
- キー色はカード枠、チップ、背景へ反映し、鳥のアクションとワンポイントの関係はコード種類ごとに固定する。

## NG

- 鳥本体へ衣装を着せる。
- コード記号をそのまま絵に入れる。
- ワンポイントが大きすぎて鳥より目立つ。
- キー違いでワンポイントの形を変える。
- mM7を黒鳥化、dimを怖すぎるホラーにする。
- add9やmaj7を派手な光エフェクトにする。
