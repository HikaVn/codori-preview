# 4鳥共通ルール

## 変えないもの

- 白い体を基準にする
- 黒い小さなくちばし
- 黒い小さな足
- やわらかい太めの線
- 1.5〜2頭身の小鳥感
- コードネームは後載せ
- キー違いで鳥種、表情、基本シルエットを変えない

---

## 変えるもの

| 変化 | 表現 |
|---|---|
| コード種類 | 鳥種、体型、表情、基本ポーズ |
| 音名 / キー | キー色、コードネーム、運指画像 |
| フォーム / voicing | 運指画像、必要に応じた小さなポーズ差 |
| テンション | 小さなアクセサリ、星、浮遊感 |

---

## 音名違いの扱い

`C` と `F` のように音名だけが違う場合、
鳥種、表情、基本シルエットは変えない。
キー色、コードネーム、運指画像で違いを出す。

例：

```text
C  → Major鳥 + C表示 + C運指 + Cキー色
F  → 同じMajor鳥 + F表示 + F運指 + Fキー色
G  → 同じMajor鳥 + G表示 + G運指 + Gキー色
```

同じコード種類を同じ鳥で覚えられることを優先する。

# 利用時の注意

## アプリ

- 鳥、コードネーム、音、運指画像を同じカード内で見せる
- 鳥と運指画像は重ねない
- クイズでは鳥と再生ボタンを同時に出す
- 音名違いはキー色、文字、運指で覚えさせる

## LINEスタンプ

- 表示文字はコードネームのみ
- 日常セリフは入れない
- コードネームはDeep Blue + 白フチを基本にする
- 背景削除後に文字を後載せする
- サウンド付き化する場合、表示コードと鳴るコードを一致させる

## SNS

- 4鳥を並べるときは、Majorを基準位置に置く
- 理論説明より感情差を先に見せる
- 小さな投稿画像では星や足が潰れる前提で構図を組む

## グッズ

- 白い体が背景に溶ける場合は外フチを強める
- 星や足などの細部は印刷サイズに合わせて太らせる
- ぬいぐるみ化では複雑な羽線を減らす
- 刺繍やピンでは小アクセントを削っても鳥種差が残るようにする
