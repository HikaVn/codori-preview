# 白い鳥アクション v7 制作ブリーフ

## 目的

v6bでそろえた11コード種類の白い鳥アクションを、学習アプリで使える品質へ近づける。

v6bは「同じ鳥としての安定感」はあるが、一部コード種類でポーズ差が弱い。
v7では、鳥種を変えず、旧C基準の白い鳥らしさを保ったまま、コード種類ごとの役割がより読めるポーズにする。

## 共通ルール

- 同じ白い鳥に見えることを最優先する。
- 鳥種を変えない。
- 目、嘴、頬、頭の比率をMajor基準から大きく変えない。
- 線幅を大きく変えない。
- 嘴の下に笑い線を追加しない。
- 眉を追加しない。
- 衣装、小物、大きなエフェクトを追加しない。
- キー違いはポーズを変えず、色だけ変える。
- 背景は淡い白〜クリーム系のまま、キャラ確認を邪魔しない。

## v7制作順

一気に全種類を変えるとキャラが揺れるため、以下の順で作る。

1. 作り直し対象: minor / m7 / maj7 / sus4 / dim
2. 微修正対象: add9 / mM7
3. 採用寄り対象: 7 / m7-5 / aug
4. Major基準との全体比較

## 作り直し対象

### minor

狙い：

```text
静か、内向き、そっと寄り添う
```

v7指示：

- Majorより少し小さくまとまる。
- 両羽を体の前へわずかに寄せる。
- 重心を少し下げる。
- 目はMajorより静かにするが、悲しすぎない。
- 泣き顔は禁止。

判定基準：

- Majorと横に並べたとき、静かな内向き感が読める。
- 暗い別キャラに見えない。

### m7

狙い：

```text
夜にほどける、力が抜ける、余韻
```

v7指示：

- minorより少しほどけた印象にする。
- 羽を下げ、体の力が抜けた立ち姿にする。
- 眠そうにしすぎない。
- 目は開いたまま、やわらかい余韻にする。

判定基準：

- minorよりも、少し大人っぽくほどけて見える。
- 眠りポーズや落ち込みポーズに見えない。

### maj7

狙い：

```text
透明、上品、遠くを見る
```

v7指示：

- 背筋を少しだけ伸ばす。
- 目線を少し遠くへ向ける。
- 首を長くしない。
- 白鳥化しない。
- Majorより静かで上品に見えるようにする。

判定基準：

- Majorより透明感があり、m7より明るい。
- 別鳥種に見えない。

### sus4

狙い：

```text
まだ待っている、未解決、着地しない
```

v7指示：

- 片足を少し浮かせる、または片羽を途中で止める。
- 体を完全に安定させない。
- きょとんとした保留感を出す。
- 不安顔にしすぎない。

判定基準：

- Majorと比べて、まだ着地していない感じが読める。
- m7-5の不安定さとは違い、怖さではなく保留感に見える。

### dim

狙い：

```text
きゅっと固まる、不思議、緊迫
```

v7指示：

- 体と羽を少し内側にまとめる。
- 足を少し近づける。
- 全体を少しきゅっとさせる。
- 怖い顔、ホラー表現は禁止。

判定基準：

- Majorより小さく固まって見える。
- mM7の宿命感、m7-5の揺れとは別の「きゅっ」とした印象になる。

## 微修正対象

### add9

狙い：

```text
きらっと見上げる、空気が広がる
```

v7指示：

- 現行v6bより目線を少し上げる。
- 頭と体をほんの少し上方向へ伸ばす。
- 羽は大きく広げすぎない。
- 星や光の小物は追加しない。

判定基準：

- Majorより軽く、上方向の空気が出る。
- augの驚きとは区別できる。

### mM7

狙い：

```text
ミステリー、過酷な運命、静かな覚悟
```

v7指示：

- 現行v6bの斜め方向を活かす。
- 目線を少し遠く、静かに張りつめた印象にする。
- 体を少し緊張させる。
- 眉、黒い羽、ホラー顔は禁止。

判定基準：

- m7より張りつめている。
- dimより怖くない。
- m7-5より宿命感がある。

## 採用寄り対象

### Major

v6bを基準として固定する。

### 7

現行v6bの片羽上げ方向を維持する。
必要なら羽先と体中心のバランスだけ微修正する。

### m7-5

現行v6bの傾き方向を維持する。
必要なら傾きすぎないよう中心を微修正する。

### aug

現行v6bの両羽広げ方向を維持する。
7の片羽上げと混同しないよう、両羽のふわっと感を残す。

## v7レビュー条件

v7生成後は、以下を必ず確認する。

- 11種類を同一サイズで並べる。
- コード名を隠して、役割の差がある程度読めるか確認する。
- Major基準の顔、目、嘴、頬、頭の比率から大きく外れていないか確認する。
- 黒輪郭が画像端に接していないか確認する。
- 本体外の離小島輪郭がないか確認する。
- アプリのカード、聞き比べ、音あてで表示確認する。

## 完了条件

v7は、以下を満たしたら正式候補に昇格する。

- Major / minor / 7 / add9の初期4種類が明確に違う。
- m7 / maj7 / mM7が、似ているが別役割として読める。
- sus4 / dim / aug / m7-5が、記号的すぎず役割を持つ。
- 全種類が同じ白い鳥として見える。
- キー違い展開しても破綻しない。
