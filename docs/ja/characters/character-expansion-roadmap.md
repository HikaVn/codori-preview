# Codori キャラクター拡張ロードマップ

## このファイルについて

2026-05-27時点で、このファイルの「新鳥種を増やす」方針は旧方針です。
本番では、元の白い鳥のアクション差分でコード種類を表します。

新しい正本：

```text
docs/ja/core/white-bird-action-system.md
```

このファイルは、
Codoriを今後どう拡張していくかを整理するロードマップ。

目的：

- キャラ増殖事故防止
- 世界観維持
- スタンプ量産整理
- 学習IP化
- 将来的なアプリ展開準備

---

# 最重要方針

Codoriは：

「大量コード辞典」

ではなく、

「感情を持つ小鳥IP」

である。

また、以下を分けて扱う。

```text
固定部分:
本番キャラクター = 元の白い鳥
コード種類 = 白い鳥のアクション違い

暫定部分:
各コード種類に対応する具体的なアクションデザイン
```

初期4鳥は、2026-05-22時点のアプリMVP用採用版。
本番では元の白い鳥のアクション差分へ置き換える。

詳細方針：

```text
docs/ja/core/white-bird-action-system.md
```

# この段階の目的

Codoriの：

- 夜感
- 余韻
- 浮遊感
- 不安感

を増やす。

ただし、Expansion Set 01の次にすぐ新鳥種へ進むとは限らない。
初心者向けには、まず `A7 / D7` のような既存7鳥のキー展開で、
「7鳥 = 次へ進みたくなる」を強化する案を優先検討する。

2026-05-23時点では、アプリMVPと練習モードが一段落したため、
本番キャラクター制作フェーズとして次期正式鳥候補を検討する。

制作判断の詳細：

```text
docs/ja/characters/next-formal-character-production-decision.md
docs/ja/production/next-formal-character-generation-brief.md
```

```text
1. m7 / 夜雀

5. m7-5 / フクロウ
```

# mM7

## 役割

ミステリーかつ過酷な運命。

minorの静けさに、maj7の張りつめた光が入るコードとして扱う。
`m7`のようにほどけず、`maj7`のようにただ透明でもない。
静かに避けられない運命を見つめる音。

## 空気感

- 月明かり
- 影のある湖
- 静かな覚悟
- 運命が動く前の沈黙

## 注意

初期アプリにはまだ入れない。
旧方針では、`m7`と`maj7`の正式鳥を固めた後に、黒鳥方向の正式候補として検討していた。
新方針では、mM7は白い鳥の「宿命を見つめるアクション」として扱う。
