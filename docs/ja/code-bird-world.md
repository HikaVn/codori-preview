# Codoriの世界

## Codoriとは

Codori（コドリ）は、
コードの響きや感情を、
小さな鳥たちとして感じられる世界です。

音楽理論を「暗記するもの」ではなく、

- 色
- 空気感
- 感情
- キャラクター

として自然に覚えられることを目指しています。

「なんだかこの子好き」
と思っていたら、
いつのまにかコードの雰囲気も覚えている。

そんな体験を大切にします。

---

# Codoriの基本ルール

Codoriでは：

- コード種類 = 鳥種
- キー = 色や光
- 展開形 = ポーズ
- テンション = アクセサリ

として表現します。

ただし、
音楽理論をそのまま図解化することは目的ではありません。

まず、
キャラクターとしてかわいいことを優先します。

---

# 世界観

Codoriたちは、
やわらかな音楽の森に暮らしています。

風が吹くと、
どこかからコードの響きが流れてきます。

少し切ない夕方、
きらきらした朝、
眠そうな夜。

同じ景色でも、
鳥によって感じ方が少し違います。

その違いが、
コードの個性になっています。

---

# 世界の雰囲気

Codoriは：

- やさしい
- 少し絵本っぽい
- あたたかい
- ふわっとしている
- 音楽が自然に流れている

空気感を大切にします。

---

# 大切にしたいこと

理論を説明しすぎないこと。

例えば：

「add9はテンションノートを含み〜」

ではなく、

「夜空を見上げたくなる響き」

として感じられることを大切にします。

---

# Codoriの役割

Codoriは：

- LINEスタンプ
- コード学習
- SNS投稿
- アプリ
- グッズ

などへ広がっていくことを想定しています。

ただし、
どの形でも：

「この子かわいい」

が最優先です。

---

# キャラクターの考え方

それぞれの鳥は、
コードの“感情”を持っています。

## 例

- Major → 明るい安心感
- minor → 少し切ない
- add9 → きらきらした空気
- m7-5 → 夜の不安感
- sus4 → まだ着地していない感じ

など。

---

# 見た目ルール

Codoriは：

- 丸い
- 小さい
- シンプル
- 小サイズでも見やすい

ことを大切にします。

LINEスタンプサイズで、
一瞬で感情が分かることを重視します。
