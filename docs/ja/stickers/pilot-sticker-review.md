# 個別レビュー

## Major「C」

良い点：

- 片羽を上げた明るい基準コード感が明確。
- 2本ハネのMajor基本形が維持されている。
- 64pxでも顔と手振りが読める。

気になる点：

- 旧日本語テキスト版からコードネーム版へ方針変更した。
- 文字を下に入れる場合、体が大きいため余白調整が必要。

修正方針：

- コードネーム版では下部に「C」を配置する。
- コードネーム版ラフ作成済み：assets/rough/stickers/pilot/chord-text/pilot_major_C_text_2026-05-21_002.png

---

## minor「Cm」

良い点：

- 考え中の羽ポーズが分かりやすい。
- Majorと違う内向き感が出ている。
- 64pxでも表情が読める。

気になる点：

- 眉がやや人間っぽく見える可能性がある。
- 文字なしだと考え中より少し不安寄りにも見える。

修正方針：

- コードネーム版では下部に「Cm」を配置する。
- 正式化時は眉を少しやわらげる。
- コードネーム版ラフ作成済み：assets/rough/stickers/pilot/chord-text/pilot_minor_Cm_text_2026-05-21_002.png

---

## 7「C7」

良い点：

- 7らしい動きと前向き感がある。
- C7らしい前へ進む感じがある。
- 最初の生成で出た人間のサイン風の羽を避け、修正版ではシンプルな上げ羽にできた。

気になる点：

- 表情が少し強め。
- 7の頭のハネと勢いが目立つため、他3鳥より少し元気に見える。
- 小アクセントは32pxでかなり小さくなる。

修正方針：

- 正式化時は眉を少しやわらげる。
- コードネーム版では下部に「C7」を配置する。
- コードネーム版ラフ作成済み：assets/rough/stickers/pilot/chord-text/pilot_seventh_C7_text_2026-05-21_002.png

---

## add9「Cadd9」

良い点：

- 見上げる表情と星でadd9らしさがある。
- 透明感と静かな感動が出ている。
- 64pxでも顔と星が読める。

気になる点：

- 32pxでは星がかなり小さい。
- 文字なしでも感動は読めるが、コード学習としては表示文字が必要。

修正方針：

- コードネーム版では下部に「Cadd9」を配置する。
- 「Cadd9」は長いため、他3つより小さくなる。
- コードネーム版ラフ作成済み：assets/rough/stickers/pilot/chord-text/pilot_add9_Cadd9_text_2026-05-21_002.png

# 小サイズ確認

## 64px

結果：

```text
4体とも顔とコード印象が読める。
Majorの安定感、minorの内向き感、7の上げ羽、add9の見上げ感が確認できる。
コードネーム版は256px確認では読める。
64pxではCadd9が小さくなるため、LINE実表示サイズでの確認が必要。
```

## 48px

結果：

```text
おおむね読める。
装飾は小さくなるが、顔と大きなポーズは残る。
短いコードネームは読めるが、Cadd9は可読性が落ちる。
この評価は旧ラフの48px確認に対するもの。
正式4鳥ベースの370 x 320候補では、`docs/ja/stickers/app-mvp-line-derivative-export.md` を正とする。
```

## 32px

結果：

```text
顔と大まかなコード印象は残る。
足、羽の細部、add9の星、7の小アクセントは潰れやすい。
本番では文字とキャラの余白設計が重要。
コードネーム版の32px確認は判断対象外。小さすぎるため、キャラ差確認用に留める。
```
