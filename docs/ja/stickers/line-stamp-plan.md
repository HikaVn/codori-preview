# Codori LINEスタンプ計画

## このファイルについて

このファイルは、CodoriのLINEスタンプ第1弾を計画するための正本メモです。

Codoriスタンプは、挨拶や日常会話のセリフを入れず、

```text
コードネーム + コード種キャラクター + 短いコード音
```

を結びつける方向で進めます。

ただし、教材っぽくしすぎず、まず「このコードの鳥かわいい」と思えるIP性を優先します。

---

# 商品方向

最終的には、サウンド付きLINEスタンプを目指します。

基本方針：

- 表示文字はコードネームにする
- サウンドは表示コードと対応させる
- 挨拶、お礼、OKなどの日常セリフは入れない
- 表情とポーズはコードの雰囲気を補助するために使う
- 音楽理論説明は入れすぎない
- 4個パイロットは承認済み
- 次はアプリMVP設計を優先し、いきなり大量生成しない

---

目的：

- 将来サウンド付きにしたとき、文字と音が自然に結びつくか確認する

# 覚えやすさ優先の仕様

ユーザーが迷わないように、
変化の役割を固定する。

| 変化する対象 | 変えるもの | 変えないもの |
|---|---|---|
| コード種類 | 鳥種、体型、表情、基本ポーズ | 音名による別キャラ化 |
| 音名 / キー | 表示文字、運指画像、小さなタグや光 | 鳥本体の色、シルエット |
| フォーム / voicing | 運指画像、必要に応じた小さなポーズ差 | 鳥種 |
| テンション | 小さなアクセサリ、星、浮遊感 | 複雑な装飾 |

例：

```text
C  と F  → 同じMajor鳥。文字と運指と小アクセントだけ変える。
Cm と Fm → 同じminor鳥。文字と運指と小アクセントだけ変える。
C7 と F7 → 同じ7鳥。文字と運指と小アクセントだけ変える。
```

鳥の違いはコード種類を覚えるために使う。
音名の違いは、コードネームと運指で覚える。

# 表示文字ルール

## 基本

- 表示文字はコードネーム
- スタンプ内の文字はコードネームだけ
- 太く、丸く、読みやすくする
- キャラの顔やシルエットを潰さない
- 長い理論説明を入れない
- 挨拶・リアクション文を併記しない
- サウンド付き化したとき、音と一致する表記にする
- コードネームは最終合成時に後載せする
- 背景削除とアルファチャンネル作成を先に済ませる

## 初期4個

```text
C
Cm
C7
Cadd9
```

## 注意点

`Cadd9` は他より長いため、以下を本番前に確認する。

- 小サイズで読めるか
- 文字が小さくなりすぎないか
- 1行コンパクト版で成立するか
- 2行表記が必要になるか

# 画像合成方針

コードネームは、画像生成時に絵の中へ直接入れない。

推奨手順：

1. 文字なしのキャラクター絵を作る。
2. 背景を削除し、キャラをアルファチャンネル付きPNGにする。
3. 輪郭、足、羽、星などの切れ・にじみを確認する。
4. 透明キャラ素材の上に、別レイヤーとしてコードネームを載せる。
5. コードネームのサイズ、色、縁取り、位置を調整する。
6. LINE実表示サイズで読めるか確認する。
7. 最終PNGとして書き出す。

理由：

- 背景削除時に文字の輪郭が荒れにくい
- コードネームだけ後から修正できる
- キー違い展開で文字を差し替えやすい
- サウンド付き化したとき、表示文字と音声ファイルの対応を管理しやすい
- 文字入り画像を再生成する必要が減る

---

# コードネーム視認性ルール

コード記号は、キャラのかわいさを邪魔しない範囲で大きくする。

暫定方針：

- 文字は太め
- 角のきつくない丸い書体
- 白いキャラ本体と混ざらない色
- 第1候補は青文字 + 白フチ
- 視認性を最優先する場合は濃いグレー文字 + 白フチ
- 必要に応じて白縁または濃色縁を付ける
- 背景透過でも読めるコントラストにする
- `C`, `Cm`, `C7` は大きく見せる
- `Cadd9` は横幅が長いため、1行コンパクト版を第一候補にする

避けること：

- 細い文字
- 薄すぎる色
- キャラの目、くちばし、足に重ねる配置
- 音楽記号や装飾を足しすぎてコードネームが読みにくくなること

---

# サウンド方針

最初の音色はウクレレを第一候補にする。

暫定方針：

- 表示文字と同じコードを鳴らす
- 1ストローク程度の短い音にする
- 余韻は短め
- スタンプ再生時に邪魔にならない音量にする
- 音源は自作または権利が明確なものだけを使う

詳細は `sound-sticker-plan.md` で管理する。

# 制作仕様確認

最終書き出し前に、LINE Creators Marketの最新仕様を確認する。

公式ガイドライン：

```text
https://creator.line.me/ja/guideline/sticker/
```

現在の通常スタンプ画像サイズ：

| 種類 | 必要数 | サイズ |
|---|---:|---|
| メイン画像 | 1個 | 240×240px |
| スタンプ画像 | 8個 / 16個 / 24個 / 32個 / 40個 | 370×320px以内 |
| トークルームタブ画像 | 1個 | 96×74px |

条件：

- PNG形式
- 背景透過
- RGB
- 72dpi以上
- 偶数px
- 画像1個あたり1MB以下
- 余白は10px程度確保

サウンド付きスタンプで追加確認するもの：

- 音声形式
- 音声の長さ
- 音声容量
- 審査条件

プラットフォーム仕様は変わる可能性があるため、
本番制作直前に公式情報で確認する。

詳細は `line-export-spec.md` で管理する。

# レビュー項目

提出前に確認する。

- キャラの種類差が分かる
- 表情が小サイズでも読める
- コードネームが読める
- 表示文字と想定サウンドが一致している
- シルエットが単純
- 色数が増えすぎていない
- 音楽記号が主張しすぎていない
- 4個または16個で同じ作品に見える
