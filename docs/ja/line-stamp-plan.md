# 現在の方針

Codoriの主軸は、ウクレレコード記憶アプリです。

LINEスタンプは、アプリ用に作成した以下の素材を使い回す派生展開として扱います。

- 鳥キャラクター画像
- コードネーム文字
- ウクレレコード音
- 透明PNG素材

---

# 重要ルール

- スタンプ文字はコードネームだけにする
- 日常あいさつ文は入れない
- 最終的にはサウンド付きスタンプを目指す
- コードネームは画像生成後に別レイヤーで合成する
- 背景削除とアルファチャンネル化を先に行う
