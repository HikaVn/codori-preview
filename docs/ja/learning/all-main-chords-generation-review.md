# Codori 全主要コード生成レビュー

## このファイルについて

このファイルは、Codoriアプリで全体像を確認するために作成した
全主要コードカタログの生成結果を記録する。

目的は、正式な全コード教材を完成させることではなく、
12音と主要コード種類をアプリ上で確認できる土台を作ること。

---

# 生成範囲

対象：

```text
12音 x 主要11コード種類 = 132コード
```

音名：

```text
C
Db
D
Eb
E
F
Gb
G
Ab
A
Bb
B
```

コード種類：

| コード種類 | 白い鳥アクション | 現在の素材 |
|---|---|---|
| Major | 安心して立つ | 元の白い鳥、`?actions=1`で候補表示 |
| minor | そっと寄り添う | 元の白い鳥、`?actions=1`で候補表示 |
| 7 | 次へ誘う | 元の白い鳥、`?actions=1`で候補表示 |
| add9 | きらっと見上げる | 元の白い鳥、`?actions=1`で候補表示 |
| m7 | グラサンでゆるく立つ | 元の白い鳥、`?actions=1`で候補表示 |
| maj7 | 透明にたたずむ | 元の白い鳥、`?actions=1`で候補表示 |
| mM7 | 不気味に笑う | 元の白い鳥、`?actions=1`で候補表示 |
| sus4 | Cと同じ丸目で空中に浮く | 元の白い鳥、`?actions=1`で候補表示 |
| m7-5 | 振り向きざまにちらっと見る | 元の白い鳥、`?actions=1`で候補表示 |
| dim | きゅっと固まる | 元の白い鳥、`?actions=1`で候補表示 |
| aug | ふわっと驚く | 元の白い鳥、`?actions=1`で候補表示 |

生成しないもの：

- Sixth
- 11th
- 13th
- altered
- 分数コード
- 複数フォーム比較
- 正式音声ファイル

# アプリ反映

アプリに以下のセットを追加した。

```text
全コード
```

表示内容：

- コードカード
- ききくらべ
- 音あて
- Web Audio仮音源
- 縦弦の運指SVG
- 鳥キャラクター

音あては、132個すべてを選択肢に出さず、
正解を含む最大6択にした。

理由：

- 初心者が圧倒されないようにするため
- 鳥だけを当てる画面にしないため
- 音、コード名、運指、鳥を少しずつ結びつけるため

## フィルタ追加

2026-05-23に、全コード画面へ以下のフィルタを追加した。

- コード名検索
- 音名フィルタ
- コード種類フィルタ

検索例：

```text
Cadd9
m7
m7-5
sus4
```

音名：

```text
すべて / C / Db / D / Eb / E / F / Gb / G / Ab / A / Bb / B
```

コード種類：

```text
すべて / Major / minor / 7 / add9 / m7 / maj7 / mM7 / sus4 / m7-5 / dim / aug
```

フィルタ後は、以下の画面が同じ絞り込み結果で動く。

- コードカード
- ききくらべ
- 音あて

例：

```text
Cadd9検索 = 1コード
m7検索 = 12コード
mM7検索 = 12コード
m7-5検索 = 12コード
sus4検索 = 12コード
C + すべて = 11コード
すべて + m7 = 12コード
C + m7 = 1コード
```

音あては、検索・フィルタ後のコードだけから出題する。
選択肢は正解を含む最大6択を維持する。

http://localhost:8000/app/?set=all-main-chords&view=compare
http://localhost:8000/app/?set=all-main-chords&view=quiz

# 運指生成の考え方

自動生成では以下を優先した。

- GCEAチューニング
- 弦は上下方向表示
- 0〜5フレット内
- コードトーンだけを含める
- なるべく低く、コンパクトな形
- ルート音をなるべく含める

注意：

自動生成した運指は、正式教材として固定する前に必ず確認する。
ウクレレでの実用性、押さえやすさ、初心者向けかどうかは、
人間の確認を通して採用・差し替えを判断する。

# 判断

現段階では、全コード作成は次の位置づけにする。

```text
正式教材完成版ではなく、全体確認用の生成カタログ。
```

トレーニング方針上は、`全コード`を図鑑モードとして扱う。
初心者の練習入口は、少数コードの練習モードに分ける。

参照：

```text
docs/ja/learning/chord-training-policy.md
```

採用できること：

- データ構造
- セット切り替え
- 12音展開の基本ルール
- Web Audio仮音源
- 縦弦の運指画像表示
- 仮鳥による学習体験の確認

まだ正式固定しないこと：

- m7 / maj7 / mM7 / sus4 / m7-5 / dim / aug の正式白い鳥アクション素材
- 全132コードの運指
- 音声ファイル
- LINEスタンプ量産
- 12キー全体のコードネーム画像

# 次のおすすめ

次は、全132コードを一気に正式化するよりも、
以下のどちらかに進むのが安全。

1. 全コード画面にお気に入り、または最近見たコードを追加する
2. `maj7 / sus4` の正式鳥候補を作る

学習アプリとしては、次にお気に入りを追加し、
よく練習するコードへ戻りやすくすると使いやすい。
