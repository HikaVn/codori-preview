# Codori トレーニングステージ設計

## このファイルについて

このファイルは、Codoriの練習モードをステージ制で整理するためのロードマップ。

目的は、コードをただ一覧で覚えるのではなく、
同じ粒度のステージを順番に進みながら、
音楽理論、キー、コード種類、コード進行を少しずつ使える形にすること。

参照：

```text
docs/ja/learning/chord-training-policy.md
docs/ja/learning/chord-key-expansion-roadmap.md
docs/ja/learning/practice-mode-mvp-spec.md
```

---

# ステージ設計の基本

Codoriのステージは、以下の単位で作る。

```text
1ステージ = 1つの学習テーマ + 少数コード + 短い進行 + かわいい言葉
```

1ステージで扱うコード数の目安：

```text
4〜8コード
```

ただし、参照用の図鑑ステージでは132コードを扱ってもよい。
その場合も、トレーニング出題は検索・フィルタ後の少数コードに絞る。

最初はStage 0 / Stage 1 / Stage 2 / Stage 5を優先実装した。
その後、Stage 3 / 4 / 6 / 7 / 8 / 9 / 10も選べるようにし、Stage 0〜10の地図を一通り歩ける状態にする。
画面構成、出題形式、データ構造は以下を正とする。

```text
docs/ja/learning/practice-mode-mvp-spec.md
```

## ステージ番号について

Codoriの練習ステージは、現時点では `Stage 0` から `Stage 10` までを基本地図とする。

最初のアプリMVPで `Stage 0 / 1 / 2 / 5` を先に出したのは、
番号が欠けているからではなく、初心者が早く体験しやすい流れを先に確認するため。

```text
Stage 0 = 入口。Cだけでコード種類の違いを見る
Stage 1 = Cメジャー周辺。曲でよく会う仲間を覚える
Stage 2 = 7鳥の道。7コードの行き先を覚える
Stage 5 = 進行の森。コードを曲の流れで聞く
```

`Stage 3 / Stage 4` は予定地として残していたが、現在はアプリ上でも選択可能にする。

```text
Stage 3 = Cメジャーのジャズ寄りダイアトニック
Stage 4 = キーを変えてみる
```

その後、`Stage 6` 以降で色づけ、minorキー、ブルージーな7、不思議な響き、全コード図鑑へ進む。

この番号は、学習の地図として使う。
実装順は、必ずしも番号順でなくてよい。
学習順は、初心者には `Stage 0 -> Stage 1 -> Stage 2 -> Stage 5` を先にすすめ、
その後に `Stage 3 / 4 / 6 / 7 / 8 / 9 / 10` を開く。

# ステージ一覧

## Stage 0: Cでコード種類をさらう

目的：

```text
同じCを使って、コード種類の違いを耳と鳥で覚える。
```

対象：

```text
C
Cm
C7
Cadd9
Csus4
Cmaj7
Cm7
Cm7-5
Cdim
Caug
```

学習テーマ：

- コード種類が変わると鳥種が変わる
- ルートが同じでも、音のきもちが変わる
- Major / minor / 7 / add9 を基準に、後続の種類を眺める

注意：

最初から11種類すべてを暗記させない。
初回は `C / Cm / C7 / Cadd9` を中心にし、
他の種類は図鑑的に少しずつ開く。

---

## Stage 1: Cメジャーのダイアトニック入門

目的：

```text
Cのまわりの仲間を覚える。
```

対象：

```text
C
Dm
Em
F
G
Am
```

後続で追加：

```text
G7
```

学習テーマ：

- Cは帰る場所
- Dm / Em / Amは静かな仲間
- F / Gは明るい仲間
- G7はCへ帰る合図

代表進行：

```text
C -> F -> G -> C
C -> Am -> F -> G
Dm -> G7 -> C
```

---

## Stage 2: 7鳥の道しるべ

目的：

```text
7コードが次の場所へ進みたがる感じを覚える。
```

対象：

```text
G7 -> C
A7 -> Dm
D7 -> G
E7 -> Am
```

学習テーマ：

- 7鳥は「次へ行こう」と言う
- 1コード単体ではなく、行き先とセットで覚える
- 進行の重力を感情で覚える

代表進行：

```text
A7 -> Dm -> G7 -> C
D7 -> G7 -> C
E7 -> Am -> Dm -> G7 -> C
```

---

## Stage 3: Cメジャーの夜の仲間

目的：

```text
7th系の響きを、夜の灯りとしてそっと聞く。
```

対象：

```text
Cmaj7
Dm7
Em7
Fmaj7
G7
Am7
Bm7-5
```

学習テーマ：

- maj7は透明な灯り
- m7は夜の余韻
- G7は帰る合図
- m7-5は少しゆれる音

代表進行：

```text
Dm7 -> G7 -> Cmaj7
Am7 -> Dm7 -> G7 -> Cmaj7
Em7 -> Am7 -> Dm7 -> G7
```

注意：

このステージは、Major / minor / 7 / m7 に慣れてから開く。
最初から理論名を重く説明しない。
「ジャズを学ぶ」より、「いつものCが夜の色になる」と伝える。

---

## Stage 4: キーを変えてみる

目的：

```text
鳥種、表情、基本ポーズは変えずに、キー色、住む枝、運指が変わることを体験する。
```

対象キー候補：

```text
C
G
F
D
A
```

学習テーマ：

- CとGで、Major鳥は同じ
- キーが変わるとコード名と運指が変わる
- 鳥の種類はコード種類で決まる

最初のキー展開：

```text
Gキー: G / Am / Bm / C / D / Em
Fキー: F / Gm / Am / Bb / C / Dm
```

注意：

12キー全部を一気に練習させない。
曲で出やすいキーから小さく広げる。

---

## Stage 5: よくある進行の森

目的：

```text
コードを単体ではなく、曲でよく出る流れとして覚える。
```

対象：

```text
C -> G -> Am -> F
C -> Am -> F -> G
F -> G -> Em -> Am
Dm -> G7 -> C
```

学習テーマ：

- 進行はコード名の列ではなく感情の流れ
- 鳥の並びで曲の景色を覚える
- 最後にどこへ帰るかを聞く

Codoriの言葉：

```text
明るく出発して、少し胸にしまって、ふわっと広がって、前へ進む。
```

---

## Stage 6: sus4とadd9の色づけ

目的：

```text
普通のMajorに、浮遊感や空気感を少し足す。
```

対象：

```text
Csus4 -> C
Gsus4 -> G
Cadd9
Fadd9
Gadd9
```

学習テーマ：

- sus4はまだ着地しない羽
- add9は空気がきらっと広がる羽
- 解決する感じ、広がる感じを聞き分ける

代表進行：

```text
Gsus4 -> G -> C
Csus4 -> C
C -> Cadd9 -> C
```

---

## Stage 7: minorキーの入口

目的：

```text
minorキーを、怖くなく、静かな森として覚える。
```

対象候補：

```text
Am
Dm
E7
G
C
F
```

学習テーマ：

- Amは静かな帰る場所
- E7はAmへ帰る灯り
- Majorキーとは違う落ち着きがある

代表進行：

```text
Am -> Dm -> E7 -> Am
Am -> F -> G -> C
Dm -> E7 -> Am
```

---

## Stage 8: ブルージーな7の森

目的：

```text
7コードのいたずらっぽさと動きを、遊びとして覚える。
```

対象：

```text
C7
F7
G7
A7
D7
```

学習テーマ：

- 7鳥は少しいたずら
- Majorよりにやっと聞こえる
- 同じ7鳥でも行き先が違う

代表進行：

```text
C7 -> F7 -> C7 -> G7
A7 -> D7 -> G7 -> C
```

注意：

ここでは理論よりも、耳で「にやっとする感じ」を覚える。

---

## Stage 9: dim / aug / m7-5 の不思議な森

目的：

```text
不安定、不思議、次へ行きたい響きを、こわがらずに知る。
```

対象：

```text
Bdim
Bm7-5
Cdim
Caug
Gaug
```

学習テーマ：

- dimはきゅっとする
- m7-5は夜のゆれ
- augは夢みたいにふくらむ

注意：

ここは初心者の必須ステージではない。
キャラIPとしては面白いが、学習では後半に置く。
「不穏」よりも「ほどける前の小さな緊張」として扱う。

---

## Stage 10: 全コード図鑑を使う

目的：

```text
必要なコードを自分で探し、小さく練習へ持っていく。
```

対象：

```text
全コード
```

学習テーマ：

- コード名検索
- 音名フィルタ
- コード種類フィルタ
- お気に入り
- 苦手コード復習

注意：

全コード図鑑は、最初の練習ステージではない。
ここは、他のステージで出会ったコードを調べる場所。
132コードを一気に覚える場所ではなく、気になる鳥を探す場所として伝える。

# 実装状態と推奨順

実装済み：

```text
Stage 0: Cでコード種類をさらう
Stage 1: Cメジャーのダイアトニック入門
Stage 2: 7鳥の道しるべ
Stage 3: Cメジャーのジャズ寄りダイアトニック
Stage 4: キーを変えてみる
Stage 5: よくある進行の森
Stage 6: sus4とadd9の色づけ
Stage 7: minorキーの入口
Stage 8: ブルージーな7の森
Stage 9: dim / aug / m7-5 の不思議な森
Stage 10: 全コード図鑑を使う
```

初心者への推奨順：

```text
Stage 0 -> Stage 1 -> Stage 2 -> Stage 5
```

その後の広げ方：

```text
Stage 3 -> Stage 4 -> Stage 6 -> Stage 7 -> Stage 8 -> Stage 9 -> Stage 10
```

アプリ上の表示：

```text
おすすめの道:
Stage 0 / Stage 1 / Stage 2 / Stage 5

もっと歩く森:
Stage 3 / Stage 4 / Stage 6 / Stage 7 / Stage 8 / Stage 9 / Stage 10
```

「もっと歩く森」はロック解除風に見せるが、MVPでは実際にロックしない。
ユーザーが興味を持ったら先にのぞけるようにする。

Stage完了後の案内：

```text
Stage 0 -> Stage 1
Stage 1 -> Stage 2
Stage 2 -> Stage 5
Stage 5 -> Stage 3
Stage 3 -> Stage 4
Stage 4 -> Stage 6
Stage 6 -> Stage 7
Stage 7 -> Stage 8
Stage 8 -> Stage 9
Stage 9 -> Stage 10
Stage 10 -> 全コード図鑑
```

これはロック解除ではなく、次に歩くと分かりやすい森を示す道しるべ。

# ステージUIの基本

各ステージは、同じ骨格にする。

```text
ステージ名
今日のコード
今日の鳥
今日のきもち
音カード
ききくらべ
音あて
進行練習
```

表示例：

```text
Stage 2: 7鳥の道しるべ
A7 -> Dm
D7 -> G
G7 -> C

そわっと進んで、次の場所へ。
```
