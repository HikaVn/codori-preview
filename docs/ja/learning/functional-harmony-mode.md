# 機能和声: 学ぶ・練習する・テスト

ホームを「学ぶ」「練習する」「テスト」の3分類に統一する。コード図鑑は「学ぶ」、既存のストーリー・音カード・ききくらべ・音あて・進行とうた練習は「練習する」から開く。既存のピアノ/ウクレレ表示、進捗保存、履歴リセットは維持する。

## 学ぶ

主調と度数、トニック（T）・サブドミナント（S）・ドミナント（D）、同じCが調によって異なる役割になる例、V7→IとIV→Iの終止を解説する。音例には主調と前後の流れを含め、現在のコードと度数を表示する。コードの明るさ・暗さだけでは機能を決めない。

## 練習する

段階1はC長調のI/IV/V（9パターン）、段階2はC/F/G長調のI/IV/V/V7（54パターン）。まずI–IV–V7–Iで主調を示し、短い間を置いて問題の進行を再生する。指定位置（★）の役割をT/S/Dの3択で回答する。対象のV/V7は次のIへ解決する。全進行を聞いた後だけ回答でき、回答後に度数・コード名・理由を表示する。聞き直しで再採点しない。

## テスト

初期6問、3/6/9問から選択できる。3問ごとにT/S/Dを1問ずつ出し、順序と進行をシャッフルする。同じ問題は重複しない。途中では正誤・コード名・点数を示さず、最後に採点と全問の進行・機能の理由を表示する。画面移動で音を止め、途中の回答はページ内に保持する。「途中終了」で回答を消して再開始できる。

## 再生・保存・範囲

音は既存のWeb Audio合成音を利用する。短い音長、キャンセル世代、予約タイマー、停止関数を既存の再生所有モジュールに追加し、移動/停止/聞き直し/段階変更で古い音を残さない。根音省略のD7運指には、このモードだけ根音を補う。元のコードデータは変更しない。

機能和声の回答記録はページ内メモリだけ。リロードすると消える。既存ストーリーの履歴・うた練習の記録は、機能和声の再生や回答で変更しない。今回の対象は転調しない長調の基本機能。iii/viには文脈によって複数の解釈があるため、単一の絶対正解として出題しない。短調・転調・代理和音・副属和音は対象外。

URLは `app/?mode=learn` / `app/?mode=practice` / `app/?mode=test`。従来の `stage` / `set` / `view` 指定も維持する。共通ホームとHistory APIで、解説・練習・テスト・既存教材を行き来できる。

## 検証

`tools/test-functional-harmony.mjs`で全63問の構成音/度数/機能、聞き終え、二重回答、停止、失敗、テストの採点非表示/均等配分を確認する。`tools/test-functional-harmony-integration.mjs`で共有音源・停止・根音補助を検証する。既存の進捗/履歴リセット、コード図、反復処理のテストもCIで実行する。ブラウザの明示検証は `tools/test-functional-harmony-ui.mjs`。無音・独立保存領域で画面移動、連打、テスト完了/再開始、既存教材の回帰を確認する。
