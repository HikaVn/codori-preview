# Codori 次の拡張判断レビュー

## このファイルについて

このファイルは、Expansion Set 01統合後に、
次の拡張をどう進めるか判断するためのレビューです。

2026-05-23追記：

```text
A7 / D7 は、既存7鳥のキー展開としてアプリに追加済み。
D7の主表示は、初心者向けに2020を採用。
2223は将来の比較候補として残す。
```

対象：

- `A7 / D7` など既存7鳥のキー展開
- `m7 / maj7` など新しい鳥種追加
- Expansion Set 01に `C` を重複表示するか

---

# 現在の状態

アプリには以下のセットがある。

```text
はじめの4羽:
C / Cm / C7 / Cadd9

Cのまわり:
F / G / Am / Dm / Em / G7 / A7 / D7
```

学習上は、初期セットの `C` を中心に、
以下をCメジャー周辺のダイアトニック入門として扱う。

```text
C / Dm / Em / F / G / Am
```

`A7 / D7 / G7` は、7鳥が次へ案内する道しるべ。

```text
A7 -> Dm
D7 -> G
G7 -> C
```

---

# 比較対象

## 案A: A7 / D7 を追加する

内容：

```text
A7
D7
```

使う鳥：

```text
7鳥
```

メリット：

- 新キャラを作らずに学習範囲を広げられる
- `A7 -> Dm`、`D7 -> G`、`G7 -> C` の流れを作れる
- 「7鳥は次へ進ませる」という記憶が強くなる
- アプリ実装コストが低い

注意：

- 7thが多くなるため、最初のかわいい入口としては少し動きが強くなる
- どのコードへ向かうかを、短い言葉で補助する必要がある

向いている目的：

```text
コード進行の流れを早く覚えたい
```

追加準備メモ：

```text
docs/ja/learning/a7-d7-expansion-prep.md
```

Codoriらしい言葉：

```text
A7 -> Dm = Dmの静かな小道へ背中を押す風
D7 -> G  = Gの前向きな風へ走り出す合図
G7 -> C  = Cへ帰りたくなる帰り道の合図
```

実装時の判断：

- D7の主表示フォームは`2020`
- `2223`は将来の比較候補
- A7 / D7はExpansion Set 01に追加済み

## 案B: m7 / maj7 の鳥種設計へ進む

内容：

```text
m7鳥
maj7鳥
```

メリット：

- ジャズ寄りダイアトニックへ進める
- Codoriの世界観に「夜」「余韻」「おしゃれ」を足せる
- キャラクターIPとしての広がりが出る

注意：

- 新キャラデザインが必要
- `minor` と `m7`、`Major` と `maj7` の差が曖昧になりやすい
- 初心者にはコード名が長く見える
- 画像生成・レビュー・小サイズ確認が必要

向いている目的：

```text
Codoriの鳥種を増やし、ジャズ寄りの学習へ進みたい
```

## 案C: Expansion Set 01にCを重複表示する

内容：

```text
C / Dm / Em / F / G / Am / G7
```

メリット：

- ダイアトニック入門として見たときに、`C` が中心にいることが分かりやすい
- `G7 -> C` の帰る先を同じセット内で確認できる
- 初心者には「Cのまわり」という意味が伝わりやすい

注意：

- 初期セットの `C` と重複する
- カード数が増えて、セットの境界が少し曖昧になる
- 同じMajor鳥の `C / F / G` が並ぶため、運指とコード名で区別する設計が必要

向いている目的：

```text
セット単体でCメジャー周辺を完結させたい
```

# 初心者目線のおすすめ順

現時点のおすすめは以下。

```text
1. CをExpansion Set 01に重複表示しないまま、文言で補助する
2. A7 / D7 を追加して、7鳥の役割を強化する（完了）
3. m7鳥を設計するか判断する
4. maj7鳥を設計するか判断する
5. m7-5 / dim系の扱いを判断する
```

理由：

- まず、現在の `Cのまわり` が学習セットとして伝わるか確認したい
- `A7 / D7` は新キャラなしでコード進行学習を広げられる
- `m7 / maj7` は魅力的だが、鳥種差の設計が必要
- `m7-5` はジャズ寄りダイアトニックで重要だが、初期には重い

# 推奨方針

2026-05-23時点では、以下で進める。

```text
Cを重複表示しない
A7 / D7はExpansion Set 01に追加済み
```

おすすめは、アプリ内では以下のどちらか。

## 推奨1: Cを重複表示しない

現在の構成。

```text
はじめの4羽: C / Cm / C7 / Cadd9
Cのまわり: F / G / Am / Dm / Em / G7 / A7 / D7
```

メリット：

- 初期4コードの役割が残る
- 追加セットがすっきりする
- 重複データが少ない

必要な補助：

```text
はじめのCを中心に...
```

のような文言で、Cが中心であることを伝える。

# 現時点のCodex推奨

現時点では、以下を推奨する。

```text
Cを重複表示しないまま、文言で補助する。
A7 / D7 は既存7鳥のキー展開として追加済み。
次は、m7鳥の設計へ進むか、E7を足すかを判断する。
```

理由：

- すでにアプリにセット切り替えがある
- 新キャラなしで学習価値を伸ばせる
- `A7 / D7 / G7 / C` は「進む音」の体感に向いている
- m7鳥は魅力的だが、minor鳥との差分設計に時間をかけたい

鳥種対応表を正式化するタイミング：

```text
A7 / D7 の既存7鳥キー展開を確認
↓
m7 / maj7 / sus4 など新コード種類の画像制作に入る直前
```

このタイミングなら、現行4鳥MVPの検証を止めずに、
新しい鳥種へ入る前に対応表を固められる。
