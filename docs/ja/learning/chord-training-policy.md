# Codori コードトレーニング方針

## このファイルについて

このファイルは、Codoriアプリを「かわいいコード図鑑」だけで終わらせず、
ウクレレコードを実際に覚えて使えるようにするためのトレーニング方針を整理する。

Codoriでは、全コードを一度に覚えさせない。
小さな森を順番に歩くように、
音、形、名前、感情、鳥を少しずつ結びつける。

ステージ制のロードマップは以下を正とする。

```text
docs/ja/learning/training-stage-roadmap.md
```

練習モードMVPの最小UI仕様は以下を正とする。

```text
docs/ja/learning/practice-mode-mvp-spec.md
```

# 基本方針

Codoriの学習体験は、以下の2つを分けて考える。

```text
図鑑モード = 探す、見る、確認する
練習モード = 覚える、聞く、押さえる、流れで使う
```

重要：

- `全コード` は主に図鑑モードとして扱う
- 初心者の入口は、少数コードの練習モードにする
- 練習では、正解率よりも「音のきもちがつながる」ことを優先する
- コード単体だけでなく、早めにコード進行の流れを扱う

---

# 図鑑モード

## 役割

図鑑モードは、コードを探して確認する場所。

主な用途：

- コード名を検索する
- 音名で絞る
- コード種類で絞る
- 鳥種とコード種類の対応を見る
- 運指画像を確認する
- 仮音源で響きを聞く。仮音源は各構成音に約20%の第2倍音を加えて聞き取りやすくする。

現在の対応画面：

```text
全コード
```

全コード画面は、以下を対象にする。

```text
12音 x 主要11種類 = 132コード
```

ただし、これは初心者が最初に全部覚える場所ではない。
図鑑は「迷ったときに見に行く森」として使う。

## 図鑑モードでやること

- コードを検索する
- コード名と運指を確認する
- 同じコード種類のキー違いを見比べる
- `m7`、`sus4` など新しい種類を軽く眺める

## 図鑑モードでやらないこと

- 全132コードを一気に暗記させる
- 全コードをランダム出題して初心者を圧倒する
- 正式確認前の自動生成運指を、完成教材として扱う
- 鳥キャラだけで正解を当てさせる

# 練習モード

## 役割

練習モードは、少数のコードを反復して覚える場所。

主な用途：

- 今日覚えるコードを少なくする
- 音を聞いてコード名を選ぶ
- コード名を見て運指を確認する
- 鳥を記憶フックにして感情を思い出す
- コード進行として流れを覚える

練習モードでは、1セットのコード数を少なく保つ。

目安：

| 練習タイプ | コード数 | 用途 |
|---|---:|---|
| はじめて | 3〜4 | 違いを感じる |
| 入門セット | 4〜6 | 曲で使う基礎を覚える |
| 進行練習 | 2〜4 | 流れと帰着感を覚える |
| 復習 | 5〜8 | 苦手コードを戻す |

# 初心者向けレベル設計

## Level 0: 音のきもちを知る

目的：

```text
コードには、明るい・静か・進みたい・広がる、という違いがあると感じる。
```

対象：

```text
C
Cm
C7
Cadd9
```

練習：

- 音を聞く
- 鳥を見る
- コード名を見る
- 運指画像を見る

ここでは押さえる速さを求めない。
まずは「違いがある」と感じられればよい。

## Level 1: Cのまわりの仲間

目的：

```text
Cを中心に、よく使う明るい鳥・静かな鳥を覚える。
```

対象：

```text
C
F
G
Am
Dm
Em
```

学習の言葉：

- C = ほっと帰る
- F = やわらかく広がる
- G = 前へ風が吹く
- Am = やさしく胸にしまう
- Dm = 少し静かな通り道
- Em = そっと影が差す

注意：

`全コード`からこの6コードを探すのではなく、
練習モードでは最初からこの小さな森として提示する。

## Level 2: 帰り道を覚える

目的：

```text
7鳥が次の場所へ案内する感じを覚える。
```

対象：

```text
G7 -> C
A7 -> Dm
D7 -> G
```

練習：

- 1つずつ聞く
- 2コードの流れで聞く
- どこへ帰りたがるかを感じる

ここでは理論用語よりも、
「次へ行きたくなる」「帰る合図」という言葉を優先する。

## Level 3: 最初のコード進行

目的：

```text
コードを単体ではなく、曲の流れとして覚える。
```

候補：

```text
C -> Am -> F -> G
C -> F -> G -> C
Dm -> G7 -> C
Am -> Dm -> G7 -> C
```

練習：

- 進行を聞く
- 鳥の並びを見る
- 1コードずつ運指を確認する
- 最後にもう一度進行で聞く

## Level 4: 余韻のコード

目的：

```text
minorより少しほどける響きや、おしゃれな響きを足す。
```

対象候補：

```text
Am7
Dm7
Em7
Cmaj7
Fmaj7
```

注意：

ここからは新しい鳥種の正式デザイン判断が必要になる。
学習では、まず `m7` を夜の余韻として扱う。

# 画面ごとの役割

## 音カード

役割：

- 1コードをじっくり見る
- コード名、鳥、運指、音、感情を結びつける

使い方：

```text
見る -> 聞く -> 運指を見る -> もう一度聞く
```

音カードは、暗記テストではなく観察の場所。

## ききくらべ

役割：

- 複数コードの違いを比べる
- Major / minor / 7 / add9 の違いを感じる
- 同じコード種類のキー違いを確認する

使い方：

```text
C と Cm を聞き比べる
C と C7 を聞き比べる
G7 と C を続けて聞く
```

ききくらべは、耳のための図鑑。

## 音あて

役割：

- 音を聞いて、コード名を選ぶ
- 運指画像と答えを確認する
- 鳥を記憶フックとして使う

やらないこと：

- 鳥だけを当てる
- 正解率だけを評価する
- 132コードを無差別に出す

音あては、テストではなく「思い出す練習」として扱う。

補助音：

- 同じ根音の選択肢では、答えと同じ根音を`土台をきく`として鳴らす。
- 根音が混ざる選択肢では、答えの根音ではなくStageの中心音を`基準をきく`として鳴らす。
- 補助音は、基音に対して約20%の第2倍音を加えて聞き取りやすくする。
- これにより、絶対音感テストにせず、かつ補助音だけで答えが確定しないようにする。
- Stageごとの中心音は`quiz_reference_root`で管理する。

## 運指確認

役割：

- 押さえる場所を確認する
- コード名とフォームを結びつける
- キャラ画像とは別に、実用情報として見る

注意：

- 運指画像を鳥に重ねない
- 運指の複数フォーム比較は後続フェーズ
- 自動生成運指は正式教材化前に確認する

## コード進行練習

役割：

- コードの並びを感情の流れとして覚える
- `G7 -> C` のような帰着感を体験する
- 単体暗記から曲で使う記憶へ進める

表示方針：

```text
コード名の列
鳥の並び
再生ボタン
短い感情メモ
```

例：

```text
G7 -> C
そわっと進んで、ほっと帰る
```

# 出題方針

## 最初は少数

初心者には、最初から多く出さない。

目安：

```text
3〜6コード
```

## 近いコードを比べる

覚えやすくするため、違いがわかる並びを作る。

例：

```text
C / Cm / C7 / Cadd9
C / F / G / Am
Am / Am7
Dm / Dm7
G7 / C
```

## 進行で覚える

単体コードを覚えたら、早めに短い進行へ進む。

例：

```text
Dm -> G7 -> C
C -> Am -> F -> G
```

## 復習は苦手優先

将来は、以下を優先して出す。

- 間違えたコード
- 最近見ていないコード
- 聞き分けが弱いコード種類
- 押さえにくい運指

---

# 全コード画面の位置づけ

`全コード`は、トレーニングの入口ではなく参照用。

使い方：

- 練習中に気になったコードを探す
- 同じコード種類をまとめて見る
- 音名ごとの運指を確認する
- 将来の教材化候補を確認する

注意：

- `全コード`の検索・フィルタ結果を、そのまま初心者練習セットにしない
- 0〜5フレット内の自動生成運指は、人間確認前の候補として扱う
- 図鑑で見つけたコードを、練習モードへ送れるようにするのは後続フェーズ

---

# 今後の実装方針

優先度の高い順：

1. 練習モードのセット設計を固定する
2. コード進行練習の最小画面を作る
3. 苦手コードを記録する
4. お気に入りコードを練習に送る
5. 全コード図鑑を正式教材化する

今はまだやらないこと：

- 新キャラ追加
- 音源制作
- 12キーの正式教材化
- LINEスタンプ量産
- 楽曲伴奏モード
