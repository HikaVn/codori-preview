# ポップス和声の9章

基礎6章と発展3章。学習マップは章を選ぶ場所、上の「学ぶ・練習する・実践する」は学び方を選ぶ場所とする。同じ章を開いたまま3分類を切り替えられる。機能和声は独立したコースではなく、第1章「機能和声の基礎：調と帰る場所」とする。ホームでは章のマップを主入口にし、コード図鑑・うた練習・音あてストーリーを「コースとあわせて使う教材」に分ける。

## 章と完成範囲

|章|目標|教材の内容|
|---|---|---|
|1 機能和声の基礎：調と帰る場所|調・度数・T/S/D・終止|既存の機能和声モジュールを再利用。音名・三和音・大文字/小文字の入口とC/Am音例を追加。長調I/IV/V/V7の練習と3/6/9問のテストを保持|
|2 調の仲間と代理コード|共通音と置換の条件|IV/ii、V→I/vi、旋律Aを固定したIV/ii比較。実践ではA/Eを保ち2か所を選択|
|3 定番進行とメロディ|型・ベース・拍・旋律を合わせて聴く|ループの回転、I–vi–IV/ii–V、旋律Gを固定したiii/I比較|
|4 ベースと声部進行|根音と最低音、共通音のつながり|C/C/E、G/G/B、旋律と内声を保った着地。転回形とベースの下降|
|5 七の和音|種類と3度/7度の動き|Cmaj7/C7、Dm/Dm7–G7–C、Bdim/Bø7。Bdim7との違いも明記|
|6 短調|主音と変化する第7音|C/Amの帰る場所、Em/E7、同じ句でG/G♯を使う比較|
|7 借用和音とセカンダリードミナント|調外音の使い道を分ける|IV/iv、Am/A7→Dm、♭VIIとV7/V。借用・主音化・転調を混同しない|
|8 追加音と配置|add/sus/テンションと音域|Cadd9/C9、Csus4/Cadd9、旋律を保ったDm9–G13–Cmaj9と配置。実践で6/9とmaj9も比較|
|9 転調と展開|寄り道と新しい主調の定着|主音化してCへ戻る句、後半G長調の句、E♭/Dへの切り替え、A短調/G長調の後半|

第1章は既存の所有モジュールに接続し、空の新教材を完成扱いにしない。第2〜9章は各3単元、A/Bの比較音例6つ、客観的な聴き分け6問、2つの選択欄による伴奏づけ1課題を実装。新規計24単元・48音例・48設問・8創作課題（各4通り）。著作権のある原曲の旋律・録音を使わず、短いオリジナルの音列で比較する。

## 教育上の判断

- ii/IVとvi/Iは、共通音や近い働きを持つ場面を教える。どこでも入れ替えられる等価物として扱わない。
- iiiは無条件のT/D選択で採点しない。vii°もVへの万能な置換とは説明しない。
- ポップスの循環は先頭＝主和音とは限らない。T/S/Dだけで説明を固定せず、型・旋律・ベース・拍・長い前後関係を手がかりにする。
- 短調のv/V7は両方試す。短調＝悲しい、1曲＝常に1つの固定音階とはしない。
- 借用は色の借用、セカンダリードミナントは一時的な行き先への導き。調外音だけで転調とは決めない。
- add9は7度を必須にせず、9の和音は通常7度を含む。susは通常3度の置換として、今回実際に鳴る構成音を示す。
- 転調を短い音例の印象だけで唯一の正解にしない。第9章の採点対象は、実際に鳴った終止の到着和音。主調の解釈は後続の継続も含めて説明する。

## 再利用する所有者

- 教材・譜例データ: `app/pops-course-data.js`。コードの実ボイシング、旋律、目標位置と事実設問を定義する。
- 章の状態・UI・バランス: `app/pops-course.js`。3単元を1回ずつ訪問してからもう一方の版を出す。6問で各単元2問、重複なし。開始/再開始で新デッキを1回作る。
- 逐次再生とキャンセル: 既存の `CodoriHarmony.createPlayer` を再利用する。
- 音色・エンベロープ・全体停止: 既存の `CodoriAudio` を再利用。`playCourseEvent` はMIDI音高を周波数へ変換し、和音と旋律を同じ所有者へ渡すだけ。イベントの音価は共通拍間隔から計算し、リリースを倍率変更しない。
- 画面・履歴・既存保存: 既存の `navigateApp` と `stopLearningAudio` を拡張する。章番号と3分類を履歴に含め、戻る/進むで再現する。
- 案内役: `app/codori-guide.js`。既存の白い鳥 `assets/approved/characters/major.png` を全画面で再利用。新規画像・別キャラ・自動アニメーションは作らない。正誤は文章とボタンでも示し、テスト途中の鳥は正解を漏らさない中立な反応にする。画像は装飾としてaltを空にし、390pxでも本文・選択肢を妨げない。

全進行を聴くまで事実問題は回答不可。対象の和音だけの聞き直しは、文脈を最後まで聴いた後にのみ可能とし、コード名は回答前に漏らさない。音声の自然な余韻が隣の和音と重なる場合にも、対象を確かめやすくする。再生/回答の連打・次問題・章移動・上の3分類・ホーム・非表示で古い音を残さない。

## 客観課題と創作の境界

事実問題の正解は、実際の譜例の対象和音・最低音・構成音から計算する。好みや「よい響き」を正誤にしない。説明は回答後に表示する。伴奏づけの候補はすべて旋律を保てるよう作り、選択ごとの違いを返す。創作には点数をつけない。

新しい章の回答・伴奏選択・メモはページ内メモリだけ。再読み込みで消えることを各画面に表示する。既存のストーリー・ピアノ設定・曲記録の保存形式やキーに変更を加えない。

## 確認方法

`app/?mode=course&chapter=1&intent=learn`。chapterは1〜9、intentはlearn/practice/test（画面表示は実践する）。第1章の従来URL `?mode=learn` / `?mode=practice` / `?mode=test` も維持する。ホームの3分類で学び方を選び、マップの章を開く。章内で3分類を切り替えても同じ章を保持する。「章を選ぶ」で現在の学び方のマップへ戻り、ブラウザの戻る/進むでも章と分類を再現する。

基礎説明の正本は第1章の「学ぶ」。練習画面に同じT/S/D解説を再掲せず、解説へのリンクを置く。第1章の出題・採点の詳細は [第1章の仕様](functional-harmony-mode.md) を参照。第1章の実践は最後に採点する確認テスト、第2〜9章の実践は採点しない伴奏づけである。音あてストーリーは別の教材として残す。

構成と遷移のHermetic検証: `node tools/test-course-navigation.mjs`。

Hermetic検証: `node tools/test-pops-course.mjs`。全章の構成・全設問・独立した構成音の正解表・全創作候補の旋律適合・出題配分・再開始・聞き終え・誤答/連打・遅延/失敗キャンセル・保存禁止境界を確認。

明示的なネイティブ検証: `tools/test-pops-course-ui.mjs`。既存PlaywrightとChromiumを `PLAYWRIGHT_MODULE` / `CHROMIUM_EXECUTABLE` で渡す。`CODORI_TEST_URL` と `CODORI_TEST_OUTPUT` を指定できる。隔離した保存領域・無音で、全章の到達/再生/回答/創作、鳥と390px、履歴、既存保存保全を確認。OfflineAudioContext 48kHzで各章の実アダプターと共通音声所有者の波形を比較し、停止後21ms以降の残音0も確認する。

通常CIにGUI・ネットワーク・個人ファイルを持ち込まない。従来の機能和声・音声・画面/履歴リセット・コード図・反復処理の回帰も保持する。
