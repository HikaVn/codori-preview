# Codori ウクレレ運指表示ガイド

## このファイルについて

このファイルは、Codoriコード記憶アプリで使うウクレレ運指画像の表示ルールを整理するガイドです。

鳥キャラクター画像とは別に、実際に押さえる場所を示す運指画像を表示する。

---

# 基本方針

Codoriアプリでは、1つのコードを以下の組み合わせで覚える。

```text
鳥キャラ
コードネーム
運指画像
音
コード印象
```

鳥キャラはコード種類の記憶フック。
運指画像は押さえる形の記憶フック。

この2つは別アセットとして管理する。

---

# 表示方向

運指画像では、弦を上下方向に表示する。

```text
弦 = 上下方向
フレット = 左右方向
```

画面上では、4本の弦が上から下へ走る。
押さえる場所は、弦の上に丸印で置く。

---

# 弦の並び

暫定方針：

```text
左から G / C / E / A
```

これは標準的なGCEAチューニングを前提にした並び。

未決事項：

- アプリ内で弦名を常時表示するか。
- 初心者向けに「いちばん右がA弦」と補足するか。
- 左利き表示を初期対応するか。

---

# フレット表示

初期表示では、必要な範囲だけを見せる。

推奨：

- 0〜3フレット中心
- 必要に応じて4〜5フレットまで拡張
- フレット線は細すぎない
- 押弦丸は大きめ
- 指番号は初期では省略または小さく表示

---

# 開放弦とミュート

初期ルール：

- 開放弦は弦の上部に小さな白丸で示す
- 押さえる弦は青い丸で示す
- ミュートは初期4コードでは使わない

将来ルール：

- ミュートは `x` で示す
- 指番号は丸の中に小さく表示できる

---

# 見た目

Codoriらしい運指画像にするため、以下を守る。

- 線はやわらかく太め
- 色数を増やしすぎない
- コードネームより目立ちすぎない
- 鳥キャラと重ねない
- 小さいスマホ画面でも見える

初期色：

```text
弦・フレット線: #263238
押弦丸: #1E5AA8
開放弦丸: white
補助線: #D8E2E8
```

# 初期4コードの仮運指

標準GCEAチューニング前提。

| 表示名 | 仮運指 | メモ |
|---|---|---|
| C | 0003 | A弦3フレット |
| Cm | 0333 | C/E/A弦3フレット |
| C7 | 0001 | A弦1フレット |
| Cadd9 | 0203 | C弦2フレット + A弦3フレット |

注意：

`Cadd9` は複数フォーム候補があり得る。
初期アプリでは `0203` を仮採用し、実音確認後に確定する。

---

# Expansion Set 01 ダイアトニック入門の運指

標準GCEAチューニング前提。
初期4コードと同じく、弦は上下方向、左から `G / C / E / A` で表示する。

| 表示名 | 仮運指 | 使う鳥 | メモ |
|---|---|---|---|
| F | 2010 | Major鳥 | Cとは違う場所でほっとする明るさ |
| G | 0232 | Major鳥 | 少し前へ風が吹く明るさ |
| Am | 2000 | minor鳥 | 静かだけどあたたかい暗さ |
| Dm | 2210 | minor鳥 | しっとり深く息をする感じ |
| Em | 0432 | minor鳥 | Cのまわりにある、そっと影が差す感じ |
| G7 | 0212 | 7鳥 | Cへ帰りたくなる風 |
| A7 | 0100 | 7鳥 | Dmへそっと背中を押す風 |
| D7 | 2020 | 7鳥 | Gへ走り出す合図 |

学習上のまとまり：

```text
C / Dm / Em / F / G / Am = Cメジャー周辺の6コード
A7 / D7 / G7 = 次の場所へ案内する7鳥
G7 = Cへ帰る案内役
```

7鳥の道しるべ：

```text
A7 -> Dm
D7 -> G
G7 -> C
```

保存先：

```text
assets/app/fingering/expansion-set-01/
```

確認用：

```text
assets/app/review/expansion-set-01/fingering-expansion-set-01-review.html
assets/app/review/expansion-set-01/fingering-expansion-set-01-review.png
assets/app/review/expansion-set-01/fingering-expansion-set-01-review-mobile.png
```

注意：

- Expansion Set 01は、アプリの`Cのまわり`セットとして表示する。
- キーが変わっても鳥種、表情、基本ポーズは変えない。
- キー違いは色で表す。
- `Em` は4フレットを含むため、0〜4フレット範囲で表示する。
- `D7` は初心者向け主表示として`2020`を採用する。
- `D7`の`2223`は、将来のフォーム比較候補として残す。

# m7入門セットの運指

標準GCEAチューニング前提。
m7は、minorより少しほどけた夜の余韻として扱う。

| 表示名 | 仮運指 | 使う鳥 | メモ |
|---|---|---|---|
| Am7 | 0000 | m7鳥 | ぜんぶ開放で、夜にふっとほどける |
| Dm7 | 2213 | m7鳥 | Dmの静けさに余韻が増える |
| Em7 | 0202 | m7鳥 | Emの影がさらっと流れる |

保存先：

```text
assets/app/fingering/m7-set-01/
```

注意：

- m7鳥は現時点では仮SVGを使う。
- 正式m7鳥の画像生成・承認後に差し替える。
- `Am7` は開放弦だけで鳴るため、m7の入口として扱いやすい。

# アプリ実装メモ

運指画像は、初期はSVGで管理する。

理由：

- 小さくしても線が荒れにくい
- 色変更しやすい
- アプリ内で再利用しやすい
- PNG書き出しもできる

将来的には、アプリ内でCanvas/SVG描画に切り替えてもよい。
