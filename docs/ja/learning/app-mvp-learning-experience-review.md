# 確認方針

初回ユーザーが、音楽理論を重く感じずに以下を結びつけられるかを確認する。

```text
コード名
鳥キャラ
運指画像
コード音
感情
```

今回の調整は文言のみ。
UI構造、キャラクター画像、運指画像、音源制作には踏み込まない。

# カード画面

## 確認

カード画面は、1コードずつ以下を確認できる。

- コード名
- 鳥キャラ
- 運指画像
- 再生ボタン
- 短い感情メモ
- 覚え方

## 調整

初心者が「理論用語」より「音の感じ」で覚えられるように、学習メモをやわらかくした。

| コード | 旧メモ | 新メモ |
|---|---|---|
| C | 明るく落ち着く基準 | ほっと帰れる明るさ |
| Cm | 少し静かで内向き | 今日は少し静か |
| C7 | 次へ行きたくなる | つぎへ行きたくなる |
| Cadd9 | 明るくふわっと広がる | ふわっと空気が広がる |

---

# 聞き比べ画面

## 確認

4コードを並べて、鳥・コード名・短いメモ・運指画像・再生ボタンを同時に確認できる。

## 判断

聞き比べ画面では、コードの違いを以下のように短く読む。

```text
C      = ほっと帰れる
Cm     = 今日は少し静か
C7     = つぎへ行きたい
Cadd9  = ふわっと広がる
```

理論名を覚える前に、音の感情差をつかむ画面として成立している。

# クイズ画面

## 確認

クイズは、鳥だけを当てる画面ではなく、
音を聞いてからコード名を選び、回答後に鳥・コード名・運指画像・感情を確認する構造になっている。

確認した流れ：

```text
音を聞く
↓
聞こえた感じに合うコードを選ぶ
↓
答えを見る
↓
音・コード名・感情・運指を結び直す
```

## 調整

テスト感を弱め、覚える補助として読めるように文言を調整した。

| 場面 | 文言 |
|---|---|
| 初期表示 | まずは音をきいて、きもちをたしかめよう。 |
| 再生後 | 近いきもちのコードをえらんでみよう。 |
| 正解 | いいね。音、コード名、きもちが少しつながった。 |
| 不正解 | だいじょうぶ。答えはコード名。もう一度、音のきもちを聞いてみよう。 |

# 判断

- 初期4コードの学習体験は、理論説明より感情と視覚フックを優先する方向に寄った。
- アプリ内の文言は、硬い学習語よりCodoriらしい小さな感情表現を優先する。
- 「鳥を当てる」ではなく「音・コード名・感情・運指をつなげる」流れになっている。
- 現時点では、UI構造の大きな変更は不要。
- 次は、実機スマホでのタップ感とWeb Audio仮音源の聞こえ方を確認する。
