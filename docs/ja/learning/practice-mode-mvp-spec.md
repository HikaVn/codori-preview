# Codori 練習モードMVP仕様

## このファイルについて

このファイルは、Codoriアプリの練習モードを最小実装するためのUI仕様です。

図鑑モードはコードを探す場所、
練習モードはコードを少しずつ覚える場所として分けます。

参照：

```text
docs/ja/learning/chord-training-policy.md
docs/ja/learning/training-stage-roadmap.md
docs/ja/learning/app-mvp-screen-spec.md
```

---

# 練習モードの目的

練習モードでは、ユーザーが以下を同時に結びつけられることを目標にします。

```text
コード名
音
運指
鳥
きもち
短いコード進行
```

重要：

- 正解率よりも、音のきもちがつながることを優先する
- 鳥だけを当てるクイズにしない
- 1ステージのコード数を少なくする
- コード単体だけでなく、早めに進行で聞く
- 全コード画面は図鑑として扱い、練習の入口にしない

---

# 最初の実装対象

練習モードでは、まず以下の4ステージを優先導線にします。

| Stage | 名前 | 役割 |
|---:|---|---|
| 0 | Cでコード種類をさらう | 同じCで、鳥種と響きの違いを知る |
| 1 | Cのまわりの仲間 | Cメジャー周辺の基本コードを覚える |
| 2 | 7鳥の道しるべ | 7コードが次へ進みたがる感じを覚える |
| 5 | よくある進行の森 | コードを曲で出る流れとして覚える |

Stage 3 / 4 / 6以降も、現在は選択可能なステージとして追加します。
ただし、初心者の最初の道は Stage 0 / 1 / 2 / 5 を優先します。

```text
Stage 3 = Cメジャーのジャズ寄りダイアトニック
Stage 4 = キーを変えてみる
Stage 6 = sus4とadd9の色づけ
Stage 7 = minorキーの入口
Stage 8 = ブルージーな7の森
Stage 9 = dim / aug / m7-5 の不思議な森
Stage 10 = 全コード図鑑を使う
```

MVPでStage 5を先に出す理由：

- 初心者が「曲っぽい流れ」を早く体験できる
- コード単体の丸暗記に寄りすぎない
- Stage 1 / 2で聞いた仲間や7鳥を、流れの中で再確認できる

表示グループ：

```text
おすすめの道:
Stage 0 / Stage 1 / Stage 2 / Stage 5

もっと歩く森:
Stage 3 / Stage 4 / Stage 6 / Stage 7 / Stage 8 / Stage 9 / Stage 10
```

「もっと歩く森」はロック解除風の見せ方にする。
ただしMVPでは実ロックはしない。
初心者にはおすすめ順を示しつつ、気になるStageは自由に開ける状態にする。
Stage 3以降は上級テストではなく、気になる響きをのぞく寄り道として扱う。
理論名は残すが、最初に読む文では灯り、余韻、ゆれ、寄り道、きらめきなどの景色を優先する。
練習中の「図鑑でさがす」は、全コード図鑑へ戻る入口として扱う。

次の森へ：

- 羽あとがそろったStageに「次の森へ」案内を表示する。
- おすすめの道は `Stage 0 -> Stage 1 -> Stage 2 -> Stage 5`。
- Stage 5が終わったら、もっと歩く森の入口としてStage 3へ案内する。
- Stage 3以降は、番号順に次のStageへ案内する。
- Stage 10完了後は、次のStageではなく図鑑モードへ案内する。
- スマホ幅ではStageボタンと練習タブを2列にして、練習本体へ進むまでの距離を短くする。

完了条件：

- 進行練習があるStage: `聞いた / 音あて / 進行` の3つ。
- 進行練習がないStage: `聞いた / 音あて` の2つ。
- 進行練習の連続再生中に次Stageへ移動しても、再生中の音は次Stageの羽あとに混ぜない。

# 画面構成

## 画面1: 練習ホーム

練習モードの入口です。

表示要素：

- ステージ一覧
- 各ステージの短い説明
- 対象コード数
- 今日のおすすめステージ
- 図鑑モードへの導線

表示例：

```text
今日はどの森を歩く？

[Stage 0] Cでコード種類をさらう
同じCなのに、きもちが変わるよ

[Stage 1] Cのまわりの仲間
Cへ帰れる小さな森

[Stage 2] 7鳥の道しるべ
次へ行きたがる音を聞いてみよう

[Stage 5] よくある進行の森
コードを流れで覚えるよ
```

注意：

- 初心者にはStage 0とStage 1を目立たせる
- `全コード` を主ボタンにしない
- 「テスト」「採点」よりも「聞いてみる」「歩いてみる」の言葉を優先する

## 画面2: ステージトップ

選んだステージの入口です。

表示要素：

- ステージ名
- 今日のきもち
- 対象コード一覧
- 代表進行
- 開始ボタン
- 練習メニュー

練習メニュー：

```text
音カード
ききくらべ
音あて
進行練習
```

初回ユーザー向けに、各メニューは短い意味が分かる表示にする。

```text
音カード = 1つずつ
ききくらべ = ちがい
音あて = 思い出す
進行練習 = 流れ
```

Stage 0では進行練習を薄く扱い、
Stage 5では進行練習を主役にします。

## 画面3: 音カード

1つのコードをじっくり見る画面です。

表示要素：

- 鳥
- コード名
- 再生ボタン
- 運指画像
- きもちメモ
- 次のコード

基本の流れ：

```text
見る
聞く
運指を見る
もう一度聞く
次へ進む
```

文言例：

```text
C
ほっと帰れる、明るい場所。

Cm
少し内側を向く、やさしい影。

C7
そわっと前へ進みたがる音。

Cadd9
空気が少し広がる、きらっとした音。
```

## 画面4: ききくらべ

2〜4コードを並べて、違いを聞く画面です。

表示要素：

- 比較対象のコードカード
- 各コードの再生ボタン
- 連続再生ボタン
- 違いのメモ

比較例：

```text
C / Cm
明るい場所と、静かな影。

C / C7
帰る場所と、次へ行きたがる音。

G7 -> C
そわっと進んで、ほっと帰る。
```

注意：

- 音を聞かずに見た目だけで判断させない
- 4コード以上を同時に詰め込みすぎない
- スマホではカードを縦に積む

## 画面5: 音あて

音を聞いて、コード名と運指を思い出す画面です。

表示要素：

- 再生ボタン
- 鳥
- 選択肢
- 回答後のコード名
- 回答後の運指画像
- 回答後のきもちメモ

基本の流れ：

```text
音を聞く
コード名を選ぶ
鳥と運指を確認する
もう一度聞く
次へ
```

重要：

- 鳥だけを当てる問題にしない
- 回答前にも鳥を見せてよいが、必ず再生ボタンも同時に出す
- 回答後はコード名、運指、鳥、きもちをまとめて見せる
- 「不正解」よりも「もう一度聞いてみよう」を優先する
- 同じ根音の選択肢では`土台をきく`を表示し、答えと同じ根音を鳴らす
- 根音が混ざる選択肢では`基準をきく`を表示し、Stageの中心音を鳴らす

## 画面6: 進行練習

コードを流れで覚える画面です。

表示要素：

- コード進行
- 鳥の並び
- 進行の再生ボタン
- 1コードずつの再生ボタン
- 感情の流れメモ
- 運指確認ボタン

表示例：

```text
Dm -> G7 -> C
静かに歩いて、そわっと進んで、ほっと帰る。
```

注意：

- 最初は演奏速度や押さえる速さを求めない
- 音の流れと帰着感を感じることを優先する
- 運指は必要なときに開けるようにする

# Stage別仕様

## Stage 0: Cでコード種類をさらう

目的：

```text
同じCでも、コード種類が変わると音のきもちと鳥が変わることを知る。
```

初期実装対象：

```text
C
Cm
C7
Cadd9
```

後続で開く候補：

```text
Csus4
Cmaj7
Cm7
Cm7-5
Cdim
Caug
```

主な練習：

- 音カード
- C / Cm / C7 / Cadd9 のききくらべ
- 音あて

出題形式：

| 種類 | 内容 |
|---|---|
| 音あて | C / Cm / C7 / Cadd9 から選ぶ |
| きもち確認 | 明るい / 静か / 進みたい / 広がる を結びつける |
| 運指確認 | 同じC周辺でも押さえ方が変わることを見る |

Codori文言：

```text
同じCの森でも、鳥が変わると空気が変わるよ。
```

## Stage 1: Cのまわりの仲間

目的：

```text
Cメジャー周辺のよく使うコードを、小さな仲間として覚える。
```

対象：

```text
C
Dm
Em
F
G
Am
```

補助：

```text
G7
```

主な練習：

- 音カード
- Major / minor のききくらべ
- Cへ帰る進行の確認
- 音あて

代表進行：

```text
C -> F -> G -> C
C -> Am -> F -> G
Dm -> G7 -> C
```

出題形式：

| 種類 | 内容 |
|---|---|
| 音あて | C / F / G / Am / Dm / Em から選ぶ |
| 運指確認 | コード名を見て運指を確認する |
| 帰る場所確認 | G7 -> C を聞いて、Cへ帰る感じを確認する |

Codori文言：

```text
Cのまわりには、曲でよく会う仲間がいるよ。Cへ帰れる感じを耳に残そう。
```

## Stage 2: 7鳥の道しるべ

目的：

```text
7コードが次の場所へ進みたがる感じを覚える。
```

初期実装対象：

```text
G7 -> C
A7 -> Dm
D7 -> G
```

後続候補：

```text
E7 -> Am
```

主な練習：

- 7コード単体の音カード
- 行き先とのききくらべ
- 2コード進行練習
- 3〜4コード進行練習

代表進行：

```text
A7 -> Dm
D7 -> G
G7 -> C
A7 -> Dm -> G7 -> C
D7 -> G7 -> C
```

出題形式：

| 種類 | 内容 |
|---|---|
| 行き先あて | A7 / D7 / G7 を聞いて、帰り先を選ぶ |
| 音あて | 7コードと行き先コードを混ぜて選ぶ |
| 進行確認 | 7鳥がどこへ案内したかを聞く |

Codori文言：

```text
7鳥は、次の枝へ案内する小さな合図。そわっとしたら、行き先とセットで聞こう。
```

注意：

- E7は便利だが、最初の実装では未追加でもよい
- 7コードは単体暗記より、行き先とセットで扱う

## Stage 5: よくある進行の森

目的：

```text
コードを単体ではなく、曲でよく出る流れとして覚える。
```

初期実装対象の進行：

```text
C -> G -> Am -> F
C -> Am -> F -> G
F -> G -> Em -> Am
Dm -> G7 -> C
```

主な練習：

- 進行を聞く
- 鳥の並びを見る
- 1コードずつ聞く
- 必要な運指だけ確認する
- もう一度進行で聞く

出題形式：

| 種類 | 内容 |
|---|---|
| 次のコード | C -> G の次に来る候補を選ぶ |
| 帰る場所 | 進行の最後がどこへ落ち着くかを選ぶ |
| 進行ききくらべ | 2つの進行を聞き比べる |
| 並び確認 | 鳥の並びとコード名の並びを確認する |

Codori文言：

```text
鳥たちが並ぶと、曲の景色が動き出す。コード名より、景色の流れを聞いてみよう。
```

注意：

- Stage 5はコード数より進行のまとまりを優先する
- 押さえる速度より、流れの記憶を優先する
- 最初は4進行程度に絞る

# 出題形式の最小セット

## 1. 音を聞いてコード名を選ぶ

用途：

- Stage 0
- Stage 1
- Stage 2

回答後に表示するもの：

```text
正解コード名
鳥
運指
きもちメモ
もう一度聞くボタン
```

## 2. コード名を見て運指を確認する

用途：

- Stage 0
- Stage 1
- Stage 5

これはクイズというより確認です。
初心者にとって、押さえ方を見る時間を十分に残します。

## 3. 2コードの流れを聞く

用途：

- Stage 1
- Stage 2

例：

```text
G7 -> C
A7 -> Dm
D7 -> G
```

## 4. 進行を聞いて並びを見る

用途：

- Stage 5

例：

```text
C -> Am -> F -> G
```

進行練習では、最初からコードを隠しすぎない。
鳥の並び、コード名、音を同時に見せて、覚える補助にする。

# データ構造

練習モード用データは、既存のコードデータを参照する別ファイルとして作る。

想定ファイル：

```text
assets/app/data/practice-stages.json
```

理由：

- 全コード図鑑データと練習ステージを分ける
- 同じコードを複数ステージで使い回せる
- ステージごとの文言、進行、出題形式を管理しやすくする

## ステージデータ案

```json
{
  "id": "stage-0-chord-families-in-c",
  "stageNumber": 0,
  "title": "Cでコード種類をさらう",
  "shortTitle": "Cのきもち",
  "status": "mvp",
  "theme": "同じCでも、鳥が変わると空気が変わるよ。",
  "primaryModes": ["sound-card", "compare", "sound-quiz"],
  "codeIds": ["C", "Cm", "C7", "Cadd9"],
  "futureCodeIds": ["Csus4", "Cmaj7", "Cm7", "Cm7-5", "Cdim", "Caug"],
  "progressions": [],
  "quiz": {
    "optionCount": 4,
    "questionTypes": ["listen-choose-name", "name-confirm-fingering"]
  }
}
```

## コード参照

コード本体は、既存データを参照します。

参照候補：

```text
assets/app/data/initial-four-chords.json
assets/app/data/expansion-set-01.json
assets/app/data/m7-set-01.json
assets/app/data/all-main-chords.json
```

練習ステージ側では、コードの実体を重複管理しない。
`codeIds`で参照し、表示文言や進行だけをステージ側に持たせる。

## 進行データ案

```json
{
  "id": "stage-5-c-am-f-g",
  "name": "胸にしまって、前へ進む",
  "codeIds": ["C", "Am", "F", "G"],
  "memo": "ほっと出発して、少し胸にしまって、ふわっと広がって、前へ進む。",
  "practiceTypes": ["play-all", "play-one-by-one", "next-chord"]
}
```

## 出題データ案

```json
{
  "type": "listen-choose-name",
  "prompt": "音を聞いて、今のコードを選ぼう。",
  "answerCodeId": "G7",
  "optionCodeIds": ["G7", "C", "D7", "Dm"],
  "afterAnswer": {
    "memo": "G7は、Cへ帰りたくてそわっとする音。",
    "showFingering": true,
    "showCharacter": true,
    "allowReplay": true
  }
}
```

# UI表示ルール

## スマホ幅

- ステージ一覧は1列
- 鳥と運指は上下配置
- 再生ボタンは親指で押しやすい大きさ
- 選択肢は2列以内
- コード進行は折り返してよい
- 運指画像を小さくしすぎない

## PC幅

- 鳥と運指を左右に並べてもよい
- 進行練習では鳥の並びを横に見せる
- ステージ説明は短く、カードを主役にする

## 文言

避ける言葉：

```text
採点
不正解
テスト
失敗
暗記しろ
```

優先する言葉：

```text
聞いてみる
もう一度
思い出す
帰る
進む
広がる
静か
そわっと
ほっと
```

# 実装メモ

最初の実装では、以下を優先します。

1. 練習ホームを追加する
2. Stage 0 / 1 / 2 / 5 を選べるようにする
3. 既存のカード / ききくらべ / 音あてをステージ単位で使えるようにする
4. Stage 5用に進行練習の最小画面を追加する
5. Stageごとの最小進捗を、ブラウザ内に軽く残す

まだやらないこと：

- 新キャラ画像生成
- 音声ファイル制作
- マイク判定
- 採点システム
- ユーザーアカウント
- 12キー全ステージ化
- LINEスタンプ量産

## 最小進捗

MVPでは、ユーザーアカウントを作らず、ブラウザ内の`localStorage`だけで軽く進捗を残す。

保存するもの：

```text
聞いた
音あてした
進行を聞いた
最後に開いていたStage
最後に開いていたタブ
最後に見ていたカード位置
最後に選んだ進行
```

この進捗は、正解率やスコアではなく、
「また同じ森へ戻ってこられる羽あと」として扱う。

表示では、各Stageに羽あと数を出し、選択中Stageには「聞いた」「音あて」「進行」の小さなバッジを表示する。
進行がないStageでは、進行バッジは将来の流れ確認用として残すが、Stage 0はまず1羽ずつ聞くことを優先する。
選択中Stageには「つづきから」を表示し、最後に見ていたタブ、カード、進行がわかるようにする。

羽あとリセット：

- Stage単位で消す。
- 「このStageの羽あとを消す」ボタンを使う。
- 実行前に確認ダイアログを出し、誤操作を防ぐ。
- 消すのはこの端末の`localStorage`に残った練習記録のみで、コードデータや画像は変えない。

初回導線：

- Stage 0を最初の1分で試せる入口にする。
- 最初に押す場所は、カード画面の青い「音をきく」。
- 次に「つぎへ」で4羽を順番に見る。
- その後「音あて」で、音・コード名・鳥・運指を結びつける。
- 図鑑モードは探す場所、練習モードは覚える場所として文言を分ける。

保存キー：

```text
codori.practiceProgress.v1
```
