# 初期対象コード

```text
C
Cm
C7
Cadd9
```

次の拡張では、初期4コードを壊さず、
別セットとして初心者頻出コードを追加する。

```text
docs/ja/learning/chord-key-expansion-roadmap.md
```

最初から全コード一覧にせず、以下のようなセット切り替えを想定する。

```text
初期4コード
初心者セット01
```

補足：

2026-05-23時点では、初回ユーザーの入口とは別に、
制作確認用の生成カタログとして`全コード`セットを追加済み。
初期学習の主導線は、引き続き`はじめの4羽`と`Cのまわり`を優先する。
`全コード`は図鑑モードとして扱い、初心者向け練習の入口にはしない。

2026-05-22時点では、アプリ上の表示名を以下にする。

```text
はじめの4羽
Cのまわり
```

`はじめの4羽` は、初期4コード `C / Cm / C7 / Cadd9` を表示する。
`Cのまわり` は、Expansion Set 01 `F / G / Am / Dm / Em / G7 / A7 / D7` を表示する。
`m7の夜` は、m7入門 `Am7 / Dm7 / Em7` を表示する。
`全コード` は、12音 x 主要11種類の生成カタログ132コードを表示する。

学習上は、初期セットの `C` を中心に、
`C / Dm / Em / F / G / Am` をCメジャー周辺のダイアトニック入門として扱う。
`A7 / D7 / G7` は、7鳥が次の場所へ案内するコードとして扱う。

```text
A7 -> Dm
D7 -> G
G7 -> C
```

注意：

- 初期4コードのデータは上書きしない
- セット単位でカード / 聞き比べ / 音あてを切り替える
- `Bdim` はまだ入れない
- D7の主表示は初心者向けに`2020`を採用し、`2223`は後続候補にする
- m7鳥は正式画像生成前のため、アプリ確認用の仮SVGを使う
- 全コードカタログでは、正式画像生成前の鳥種を仮SVGで表示する
- 全コードカタログの運指は自動生成のため、正式教材化前に人間が確認する

# 画面2: 聞き比べ

表示中のセット内で、コードの違いを音で覚える画面。

初期4コードでは、Major / minor / 7 / add9 の違いを聞き比べる。
Expansion Set 01では、Cメジャー周辺の仲間として、
Major鳥、minor鳥、7鳥の役割を聞き比べる。

## 表示要素

- 2つのコードカード
- それぞれの再生ボタン
- 違いを表す短いメモ

例：

```text
C  → 明るい基準
Cm → 静かな内向き
```

# 画面3: クイズ

初期クイズは軽くする。

## クイズ種類

- 音を聴いてコードネームを選ぶ
- コードネームを見て音を確認する
- 運指画像を見てコードネームを選ぶ

将来追加候補：

- コードネームを見て鳥を選ぶ
- 鳥を見てコードネームを選ぶ

初期MVPでは、鳥キャラと再生ボタンを同時に表示し、
音・コード名・鳥キャラを同時に結びつけるクイズを優先する。
目的は絵だけを当てることではなく、鳥を記憶フックにしながら音を聞き分けること。
回答後は、正解コード名・鳥キャラ・運指画像・短いメモを同時に表示し、
聞こえた音を実際のフォームへつなげる。

正式4鳥ベースのMVPでは、
選択肢は音を一度再生してから押せるようにする。
回答後は聞き直しできるが、同じ問題を再回答できないようにする。
「次の問題」は回答後だけ押せるようにする。

理由：

- 鳥だけを見て当てるクイズにしない
- 音を聞く行動を必ず学習フローに入れる
- 鳥、音、コード名、運指画像を順番につなげる

全コードカタログでは対象が132コードになるため、
音あての選択肢は正解を含む最大6択にする。
これはテストを難しくするためではなく、
音・コード名・運指・鳥の結びつきを少しずつ育てるため。

全コードカタログでは、コード名検索、音名フィルタ、コード種類フィルタを表示する。
検索とフィルタはカード / ききくらべ / 音あてで共通して使う。
これにより、初心者が132コードを一度に受け止めるのではなく、
「Cだけ」「m7だけ」「Cadd9だけ」のように小さな森へ分けて確認できる。

ただし、これは参照・確認用の図鑑モードであり、
練習モードでは3〜6コード程度の小さなセットを優先する。

# 練習モード方針

今後の練習モードでは、以下を優先する。

- 1セットを少数コードにする
- 音あてはテストではなく思い出す練習にする
- 運指確認は鳥キャラとは別に見せる
- コード単体だけでなく、短いコード進行を早めに扱う

最初に扱う流れ：

```text
G7 -> C
A7 -> Dm
D7 -> G
Dm -> G7 -> C
C -> Am -> F -> G
```

# 運指画像表示ルール

運指画像は、キャラクター画像と別に表示する。

```text
弦 = 上下方向
フレット = 左右方向
```

注意：

- 鳥キャラに重ねない
- コードネームを隠さない
- 1画面に複数フォームを詰め込まない
- 初期ではGCEAチューニングを前提にする
