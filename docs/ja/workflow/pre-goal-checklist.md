# pre-goal-checklist.md

# Codori /goal 実行前チェックリスト

## このファイルについて

このファイルは、
Codoriプロジェクトを：

```text
/goal
```

で大規模実行する前に、
最低限固めるべき項目を整理するためのガイド。

目的：

- Codex暴走防止
- 世界観崩壊防止
- キャラ増殖事故防止
- 無駄生成削減
- “Codoriらしさ”維持

---

# 最新結論

## 現段階では、アプリMVP設計に限定した /goal は実行可能。

理由：

- Codoriの主軸が「ウクレレコード記憶アプリ」として整理された
- 初期4鳥、コードネーム表示、LINEサイズ確認、運指画像試作は進んだ
- 初期4鳥とDeep Blue文字スタイルはユーザー承認済み
- `assets/approved/` への正式参照整理も完了
- 音源はMVPでは仮音源から始める
- 次フェーズはアプリMVP設計を主目的にする

つまり現在は、

```text
IP設計フェーズ後半
↓
アプリMVP準備フェーズ入口
```

にいる。

# なぜ危険か

この状態で：

```text
/goal
「CodoriアプリとLINEスタンプを一気に完成させて」
```

をやると：

- 絵柄崩壊
- 別作品化
- アプリ仕様とスタンプ仕様の混線
- コードデータ不整合
- 運指画像とキャラ画像の混在
- 音源仕様の後戻り
- 大量生成による品質低下

が起きやすい。
