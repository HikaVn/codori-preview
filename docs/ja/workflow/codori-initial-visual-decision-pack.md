# codori-initial-visual-decision-pack.md

# Codori 初期ビジュアル決定パック

## このファイルについて

このファイルは、
Majorを起点に初期4鳥のビジュアル方向を決めたあと、
その結果を記録し、
次の `/goal` 実行へ進めるか判断するための一括パック。

目的：

- 生成結果を感覚だけで終わらせない
- 採用理由を残す
- 不採用理由も残す
- 次の量産前に絵柄基準を固定する
- AGENTS.md / CODEX_GOAL.md / FIRST_MESSAGE.md を更新する準備をする

---

# 現在のフェーズ

現在のCodoriは：

## ビジュアル基準固定フェーズ

にいる。

ここで決めるべきことは：

- Majorの正式方向
- minorとの差
- 7との差
- add9との差
- 4鳥の統一感
- LINEスタンプサイズでの見え方
- 白黒シルエットでの識別性

---

# このパックでまとめて進めること

以下を一括で進める。

1. 画像生成結果の整理
2. 採用候補の選定
3. 4鳥比較
4. 白黒シルエット結果の記録
5. LINEサイズ確認結果の記録
6. 修正点の整理
7. /goal実行可否判断
8. AGENTS / CODEX_GOAL / FIRST_MESSAGE 更新準備
