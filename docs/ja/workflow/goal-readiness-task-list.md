# Codori /goal 実行前タスクリスト

## このファイルについて

このファイルは、Codoriを `/goal` で大きく進める前に必要なタスクを整理するチェックリストです。

現在のCodoriは、LINEスタンプ単体ではなく、

```text
メイン = ウクレレコード記憶アプリ
派生 = LINEサウンド付きスタンプ / SNS / 教材 / グッズ
```

として扱う。

そのため、`/goal` 実行前には、キャラクターIPだけでなく、
学習アプリとしての最低限の構造も固める必要がある。

---

# 結論

現時点で、正式4鳥ベースのアプリMVP確認とLINE候補確認に進行可能。

理由：

- 初期4鳥は正式採用済み
- コードネーム表示方針も承認済み
- LINEサイズ確認もできている
- 学習アプリ用の運指画像・コードデータ・画面構成も最小仕様まで整理済み
- approved画像フォルダへの正式反映も完了

ただし、以下は `/goal` 後またはMVP制作中に扱う。

- 音源の実制作
- アプリ画面ワイヤーの具体化。初回Webプロトタイプは `app/` に作成済み
- 透過PNG化とコードネーム後載せ本番合成
- LINE公式仕様の本番前再確認
