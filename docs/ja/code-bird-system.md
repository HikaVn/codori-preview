# Codoriコード体系

## 基本ルール

Codoriでは：

- コード種類 = 鳥種
- キー = 色や光
- 展開形 = ポーズ
- テンション = アクセサリ

として表現します。

---

# 最重要ルール

## 展開形で別キャラ化しない

同じコードなら、
押さえ方が違っても同じ鳥です。

違いは：

- ポーズ
- 羽の開き方
- 姿勢
- 表情

などで表現します。

# 色ルール

## コード種類

コード種類ごとに、
基本カラーを持つ。

例：

- Major → 黄色系
- minor → 青系
- add9 → 水色系

など。

---

## キー

キーは：

- 小さなタグ
- 光
- 星
- 月
- オーラ

などで追加表現する。

---

# ♯ / ♭

- 星
- キラッとした光

---

## ♭

- 月
- やわらかい影

# デザインルール

- 小サイズで読める
- シルエットで分かる
- 色数を増やしすぎない
- 細かすぎる装飾を避ける
- “かわいい”を優先する

---

# 避けること

- inversionごとに別鳥化
- キーごとに全身色変更
- 理論ごとの細かすぎる分類
- 情報量過多
