# Codori / Code Bird World

## Purpose

Codori is a cute character IP built around chord learning. Each character is a small bird that represents a chord quality or chord family, making harmony feel friendly, collectible, and easy to remember.

The world should work first as character design. Music theory supports the IP, but the IP should not become a diagram system that only musicians can enjoy.

## Core Concept

Codori lives in a soft musical world where chords are expressed as bird personalities. A chord is not treated as a technical formula first. It is treated as a recognizable friend with a clear silhouette, mood, and visual hook.

The name can be read as:

- Chord: musical harmony and chord feeling
- Dori: a soft bird-like Japanese sound
- Codori: little birds that help people remember musical feelings

## World Principles

- Cute before technical
- Simple before detailed
- Recognizable before realistic
- Character family before one-off variation
- One chord family per character
- No separate characters for voicings
- Limited color logic
- Scalable forms for small stickers, icons, and merchandise

## World Tone

Codori should feel:

- Warm
- Gentle
- Playful
- Musical but approachable
- Easy to collect
- Easy to explain
- Appealing to beginners and non-musicians

Codori should not feel:

- Overly academic
- Visually noisy
- Too many colors at once
- Like a full music theory textbook
- Like abstract notation with eyes added

## Setting

Codori characters live in a small musical habitat called the Codori Forest.

The Codori Forest is not a complex lore universe. It is a simple flexible setting for images, stickers, learning scenes, and social media posts.

Recommended recurring locations:

- Staff Line Meadow: open space with subtle staff lines as ground texture
- Rest Nest: calm place for sleepy or relaxed expressions
- Melody Branch: perch used for singing, posing, or teaching
- Circle Pond: location for chord family grouping and relationship diagrams
- Sticker Stage: plain background area for LINE sticker compositions

These locations are optional visual supports. The character should still be recognizable without them.

## Character Role

Each Codori character represents a chord family. The character expresses the emotional quality of that chord through:

- Body shape
- Eye expression
- Pose
- Wing gesture
- Small accessories
- A controlled accent color
- A simple music-symbol motif

The chord name should be usable as a label, but the character design must still work when the label is removed.

## IP Scalability

### LINE Stickers

Characters need large readable expressions, compact silhouettes, and simple poses. Stickers should communicate emotions such as joy, thanks, surprise, sleepy, thinking, cheering, sorry, and OK without requiring music knowledge.

### Chord Learning

Characters can teach chord quality, not every possible voicing. Learning assets should connect the character to intervals, chord symbols, emotional color, and examples, but the core character design should remain stable.

### Apps

Characters can become interactive guides, quiz avatars, progress badges, unlockable collections, and lesson companions. App icons should use the simplest head or full-body silhouette.

### Merchandise

Characters should work as plush toys, acrylic stands, keychains, stickers, pins, notebooks, and apparel. Avoid details too thin for embroidery, small prints, or molded goods.

### Social Media

Characters should support square posts, vertical videos, reaction images, short educational carousels, and seasonal posts. Social assets should use the same character rules as product assets.

## Visual Language

### Base Shape

Use a compact rounded bird shape:

- Round head and body, either merged or lightly separated
- Short wings
- Tiny feet
- Small beak
- Big expressive eyes
- Simple crest, feather, or accessory only when meaningful

### Silhouette

Every main character should be recognizable in one-color silhouette at small size.

Strong silhouette anchors may include:

- Crest shape
- Wing position
- Tail shape
- Accessory shape
- Overall body proportion

Avoid silhouette differences based only on tiny marks, fine line details, or color.

### Color

Use a restrained palette. Color helps separate character families, but the project should not create excessive color variants.

Recommended approach:

- One main body color per character
- One accent color per character
- Shared beak and foot colors across the whole cast
- Shared line color across the whole cast
- Backgrounds kept simple and lower contrast than characters

### Music Motifs

Music motifs should be simple and secondary. Good motifs include:

- One note mark
- One small accidental mark
- A staff-line perch
- A tiny chord-symbol tag
- A subtle interval icon

Avoid turning characters into notation charts.

## Core Cast Direction

The first cast should cover the most useful chord qualities while keeping the number of characters manageable.

Suggested starter cast:

- Major
- Minor
- Seventh
- Major Seventh
- Minor Seventh
- Diminished
- Augmented
- Suspended
- Sixth
- Ninth / Extension

The starter cast can be reduced for the first image production batch if needed. A smaller polished set is preferable to a large inconsistent set.

## Naming Direction

Names should be short, cute, and usable in Japanese or English contexts. The chord symbol can remain separate from the character name.

Example pattern:

- Majo: major chord bird
- Mino: minor chord bird
- Sebu: seventh chord bird

These are temporary examples, not final names.
