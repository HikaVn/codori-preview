# Codori Sound Assets

このフォルダは、Codoriを将来的にサウンド付きスタンプへ展開するための音声素材置き場です。

## 方針

- 表示文字と同じコード音を対応させる
- 初期4個は `C`, `Cm`, `C7`, `Cadd9`
- 音色はウクレレを第一候補にする
- 音源は自作または権利が明確なものだけを使う
- LINEの最終仕様は本番書き出し前に公式情報で確認する

## フォルダ

```text
source/  元録音・元データ
export/  LINE仕様に合わせた書き出し候補
review/  確認用の試聴・比較素材
```

## 初期ファイル名案

```text
codori_sound_01_C_ukulele.wav
codori_sound_02_Cm_ukulele.wav
codori_sound_03_C7_ukulele.wav
codori_sound_04_Cadd9_ukulele.wav
```
