## メモ

- 既存4鳥は再デザインしていない。
- 小鳥アイコンはロゴ用の簡略シンボル。
- 色数は少なくし、Deep Blueと白鳥世界観を優先する。
- ロゴ方針は `docs/ja/core/logo-style-guide.md` を正本とする。
- プレビュー画像は確認用であり、正式書き出しではない。
- rough-02は、rough-01の頭のハネと足の違和感を抑えた非破壊修正版。
- rough-03は、頭のハネを背面寄りにし、足を体の下に少しだけ見せる非破壊修正版。
- rough-04は、足を省略し、頭のハネをさらに小さくしたロゴ用途向けの非破壊修正版。
- codori-logo-app-header-rough-04.svgは、rough-04をアプリヘッダー用に読みやすくした派生版。
- rough-04を現フェーズのロゴとして固定済み。
- 正式採用前に商標・類似ロゴ確認を行う。
