# Codori 正式候補アセット作業場所

このフォルダは、正式採用前の初期4鳥素材をレビューするための作業場所です。

`assets/approved/` は承認済み素材だけを置く。
正式化中の候補は、まずこの `assets/formal/` に置く。

## フォルダ

```text
characters/
lineups/
checks/
```

## characters/

個別の正式候補を置く。

例：

```text
major_formal_candidate_001.png
minor_formal_candidate_001.png
seventh_formal_candidate_001.png
add9_formal_candidate_001.png
```

## lineups/

4鳥を並べた比較画像を置く。

例：

```text
initial_four_formal_lineup_001.png
```

## checks/

小サイズ確認、白黒シルエット確認、LINEサイズ確認などを置く。

例：

```text
initial_four_formal_lineup_001_64px.png
initial_four_formal_lineup_001_silhouette.png
```

## 昇格ルール

ユーザー承認後にのみ、必要な素材を `assets/approved/characters/` へ移す。

承認前に `assets/approved/` を上書きしない。
