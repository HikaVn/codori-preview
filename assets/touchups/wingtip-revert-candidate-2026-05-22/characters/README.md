# Codori 羽先端 追加割れ撤回候補

ユーザー確認により、前回の羽先端タッチアップ候補は以下の理由で不採用。

- Cmの変化が内側の線に見え、輪郭線だけの割れになっていない
- C7の割れ位置が外側に出すぎ、C基準から外れている
- Cadd9の左手側だけ割れておらず、左右の見え方が不均衡
- ラスター局所編集では、Cのお手本のような自然な小さな輪郭割れ品質を保ちにくい

この候補は、追加した割れ線を撤回し、正式4鳥の元画像に戻した非破壊候補です。
