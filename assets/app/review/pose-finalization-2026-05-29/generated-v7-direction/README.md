# v7方向参考シート

## 扱い

このフォルダの画像は、コード種類ごとのポーズ差を検討するための方向参考です。

旧C基準の顔、線、頭身から外れているため、そのまま本番アセットとしては採用しない。

## 採用する考え方

- minorは羽を内側へ寄せる。
- 7は片羽を上げる。
- add9は上方向を見る。
- m7は力を抜く。
- maj7は上品に遠くを見る。
- mM7は斜め方向と遠い目線で宿命感を出す。
- sus4は片足または片羽で未解決感を出す。
- m7-5は傾きで揺れを出す。
- dimは内側へ固まる。
- augは両羽を広げる。

## 採用しない表現

- 鳥種が変わる表現
- 眉、怖い顔、開きすぎた嘴
- 衣装、小物、過剰な影
- 旧C基準から大きく外れた頭身
