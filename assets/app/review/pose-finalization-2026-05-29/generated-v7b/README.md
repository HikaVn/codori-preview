# v7b生成シート

## 扱い

v7方向参考シートをもとに、旧C基準へ寄せ直して再生成した候補シートです。

このシートから個別に切り出した画像を、以下の候補フォルダへ配置している。

```text
assets/app/characters/action-candidate-old-c-v7/
```

## 生成時の主な制約

- 旧C基準の白い鳥として見えること。
- 嘴は閉じる。
- 眉、衣装、小物、音符、星を追加しない。
- コード名や文字を画像内に入れない。
- 11種類のシルエット差をv6bより強める。

## 残る注意点

- 旧C基準より少し手描き感が強い。
- minorとdimは前羽の使い方が近いため、最終化前に差の確認が必要。
- app表示ではv7を候補として参照するが、正式採用前の確認段階とする。
