# Codoriポーズ最終化レビュー v6b

## 結論

v6bは「アプリに仮反映できる候補」だが、最終完成ではない。

11コード種類の画像はそろっているが、コード種類ごとの記憶補助として見ると、ポーズ差が弱いものがある。
特に、静かな系統の `minor / m7 / maj7 / sus4 / dim` は、並べたときの違いが小さく、学習上の手がかりとして不足している。

## v7で固定すること

- Majorは基準として固定する。
- 7 / m7-5 / augは方向性を維持し、微調整に留める。
- minor / m7 / maj7 / sus4 / dimは作り直し対象にする。
- add9 / mM7は方向性を残して微修正する。
- 鳥種変更、眉、衣装、小物追加、過剰な影は禁止する。
- キー違いではポーズを変えず、色だけ変える。

## v7制作指示の要点

### Major

旧C基準の安心ポーズ。変更しない。

### minor

Majorより少し内向き。
両羽を体の前へわずかに寄せ、体の重心を少し下げる。
悲しすぎる顔、泣き顔は禁止。

### 7

片羽で次へ誘う。
現行v6bの片羽上げ方向を維持する。
悪役顔やいたずらが強すぎる表情は禁止。

### add9

少し上を見上げる。
体をほんの少し伸ばし、空気が軽く広がる印象にする。
星、光、小物は追加しない。

### m7

夜にほどける。
羽を少し下げ、力が抜けた立ち姿にする。
眠り顔にしすぎず、目はCodoriらしく残す。

### maj7

透明にたたずむ。
姿勢を少しだけ上品にし、遠くを見る。
白鳥化、首長化は禁止。

### mM7

ミステリーかつ過酷な運命。
現行v6bの斜め方向を活かし、静かな覚悟が出るように目線を調整する。
怖い顔、眉、黒鳥化は禁止。

### sus4

まだ着地しない。
片足を少し浮かせる、または羽を中途半端に止める。
不安顔にしすぎない。

### m7-5

少し揺れる。
現行v6bの傾き方向を維持する。
怖さより、緊張と不安定さを優先する。

### dim

きゅっと固まる。
体と羽を少し内側へまとめ、足も近づける。
ホラー化は禁止。

### aug

ふわっと驚く。
現行v6bの両羽広げ方向を維持する。
極楽鳥化、大きな羽飾りは禁止。

## 次アクション

v7では、全11種類を一度に大きく変えず、以下の順で作る。

1. 作り直し対象の5種: minor / m7 / maj7 / sus4 / dim
2. 微修正対象の2種: add9 / mM7
3. 採用寄りの3種: 7 / m7-5 / aug
4. Major基準との並び確認

完了条件は、11種類を同一シートで並べたとき、コード名を隠しても役割の違いがある程度読めること。
