# 旧アプリ初期C基準アクション案レビュー

## 目的

旧アプリ初期版のC鳥を正として、コード種類ごとの白い鳥アクションを作り直すための初回案。

重視した点：

- 体型、目、嘴、頬、羽、足を旧Cに寄せる
- コード種類は鳥種差ではなく微アクション差で表す
- キー違いへ展開しても同じキャラに見える範囲に抑える
- 嘴の下に余計な笑い線を入れない
- 眉、衣装、小物、別種化を避ける

## 現時点の判断

`v6b`の方が旧C基準として安定。

理由：

- 全体の顔、体型、線幅が旧Cに近い
- 目を閉じた個体がなく、キャラの揺れが少ない
- アクション差が小さく、同じ鳥のバリエーションとして見える

注意：

- Majorとminorの差はかなり小さい。
- mM7は旧C基準に寄せたため、過酷な運命感は弱め。
- `?actions=1` の学習アプリ表示は、v6bの個別切り出しを参照する。
- このシートと個別画像はレビュー用で、まだ正式な透明背景アセットではない。
