# Expansion Set 01 Fingering SVG

Codoriアプリ用の初心者セット01運指SVGです。

対象：

```text
F
G
Am
Dm
Em
G7
A7
D7
```

前提：

- チューニングは標準GCEA
- 弦は上下方向
- 弦の並びは左から `G / C / E / A`
- 初期4コードのSVGと同じ見た目に揃える
- `Em` は4フレットを含むため、表示範囲は0〜4フレットを使う
- `A7` は `0100`
- `D7` は初心者向け主表示として `2020`
- `D7` の `2223` は、将来のフォーム比較候補としてdocsに残す

注意：

- `assets/app/data/expansion-set-01.json` から参照するアプリ用アセット。
