# Codori Initial Four Ukulele Fingering Assets

このフォルダは、Codoriウクレレコード記憶アプリの初期4コード用の運指画像を置く場所です。

## 方針

- 鳥キャラ画像とは別アセットとして管理する
- 弦は上下方向に表示する
- フレットは左右方向に表示する
- 標準GCEAチューニングを暫定前提にする
- 初期はSVGで管理する

## 初期4コード

```text
C      0003
Cm     0333
C7     0001
Cadd9  0203
```

## 注意

`Cadd9` は `0203` を仮採用している。
実音確認後に確定する。
