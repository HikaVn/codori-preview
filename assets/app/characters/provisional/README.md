# Codori アプリ用仮キャラクター

このフォルダは、正式画像生成前にアプリ学習体験を確認するための仮キャラクター素材を置く場所です。

## 現在の素材

```text
m7-night-sparrow.svg
maj7-swan.svg
sus4-penguin.svg
m7b5-owl.svg
dim-little-owl.svg
aug-bird-of-paradise.svg
```

用途：

- `m7`コード種類の仮表示
- Am7 / Dm7 / Em7 のアプリ学習確認
- minor鳥との差分確認
- 全主要コードカタログで、正式画像生成前の新鳥種を仮表示する

対応：

| コード種類 | 仮素材 | 正式候補 |
|---|---|---|
| m7 | `m7-night-sparrow.svg` | 夜雀 |
| maj7 | `maj7-swan.svg` | 白鳥 |
| sus4 | `sus4-penguin.svg` | ペンギン |
| m7-5 | `m7b5-owl.svg` | フクロウ |
| dim | `dim-little-owl.svg` | コキンメフクロウ |
| aug | `aug-bird-of-paradise.svg` | 極楽鳥 |

注意：

- 正式採用キャラクターではありません
- `assets/approved/characters/` へはまだ移しません
- 正式鳥を画像生成・承認したら差し替えます
