# 白い鳥アクション候補 2026-05-27

## このフォルダについて

このフォルダは、アプリ上で白い鳥アクション方式を確認するための候補画像置き場です。

正式採用アセットではありません。

正式採用前のため、`assets/approved/characters/` は上書きしません。

## 使い方

アプリURLに以下を付けると、この候補画像をコード種類ごとに表示します。

```text
?actions=1
```

例：

```text
app/index.html?actions=1&set=all-main-chords
```
