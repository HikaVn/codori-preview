# 旧C基準白い鳥アクション候補 v7

## このフォルダについて

旧アプリ初期版のC鳥を基準にしつつ、v6bよりコード種類ごとのポーズ差を強めた学習アプリ用候補です。

現時点では正式本番素材ではなく、学習画面で差の読みやすさを確認するための候補として扱う。

## 注意

- v6bより差は出ているが、旧C基準より少し手描き感が強い。
- minorとdimはどちらも前羽を使うため、最終化時にはさらに差を確認する。
- add9とaugはどちらも上方向の動きがあるため、アプリ表示で混同しないか確認する。
- キー違いではポーズを変えず、色だけ変える方針を維持する。
